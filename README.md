# DEADLOCK: Since 1988

Unity（URP）で開発する、iOSなどのモバイル向けレトロ3D PvPvEシューター。

背景は粗いレトロ表現、手元の武器・腕は精細な2Dスプライト。対人戦とモンスター戦で生き残り、上位報酬のガチャポイントで装備やスキルを増やします。

## 基本方針

- 対戦規模は4〜8人程度。不足時は対戦BOTを補充。
- モードはトレーニング、デッドライン、ラストスタンド。
- 武器・スキルは永続所有。死亡による装備喪失なし。
- ガチャはスキン・武器・スキルの3カテゴリ。
- 100ポイントで単発、1,000ポイントで11連（11枠中1枠を保証。保証内容は未決定）。
- デッドラインの通常報酬は、生存者の1位10ポイント・2位5ポイント・3位3ポイント。
- メイン銃＋近接武器、パッシブ1枠＋アクティブ1枠。
- 試合開始前約30秒で装備・プリセットを変更。
- 武器種ごとのカスタム解放。弾倉は予備弾増加／装填数増加から選択。

## 開発体制

仕様と作業指示をチャットで整理し、ローカルのClaude Codeで実装・検証・コミットを行います。GitHubは仕様と変更履歴の共有に使用します。

Unityバージョン、対象端末、ローカル環境の構築手順、初期実装範囲は今後確定します。現時点で起動・ビルド手順はありません。
