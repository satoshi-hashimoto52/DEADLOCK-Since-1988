## 2. 共通の画風（確定：D-041・D-043）

基準の画像は、採用済みのライフルの腰だめと ADS です。

- **画風：** レトロ FPS 向けの 2D ピクセルアート。金属・グローブ・袖の質感を、ドットの形と陰影で表します。
- **ドットの大きさ：** 1ドットは約4画素（最終出力の大きさで）。既存のライフルと同じ粗さにします。
- **輪郭と陰影：** 太い暗い輪郭（2〜3ドット）と、段階的な陰影（材質ごとに4〜5段階が目安）。
- **使わない表現：** ぼかし・グラデーション・ノイズ・アンチエイリアス・光のにじみ・写真的な質感。
- **アルファ：** 最終出力のアルファは0か255です。半透明の縁は作りません。
- **背景：** 透明です。床・影・背景・文字は描きません。
- **色空間：** sRGB の前提で描き、ICC プロファイルは埋め込みません（既存の画像も埋め込んでいません）。
- **時代感：** 1980年代の軍用銃の雰囲気です。特定の実在する銃をそのまま写さないでください。
- **見やすさ：** 暗い背景でも明るい背景でも、形が読めるようにします。
- **一人称の手（既存と同じ）：**
  - 茶色の革のグローブ（補強の当て布つき）
  - 暗い色の手首のバンド
  - オリーブ色の迷彩の袖

### 2-1. 色替え（スキン）に対応する描き方

- 色を変える部品（外装・銃床・ハンドガードなど）は、1つの色の系統でまとめます。ゲームは色相の範囲で領域を取り出します。
- 色を変えない部品（暗い鋼・照準器・黒い弾倉と握りなど）は、色を変える部品とはっきり違う色にします。
- 次の境目には、暗い輪郭を入れます。
  - 色を変える部品と、変えない部品の間
  - 銃とグローブの間
  - グローブと手首のバンドの間
  - 手首のバンドと袖の間
- 色替え用の領域図・配置ファイル・アルファを2値にした派生画像は、こちらでツールを使って作ります。画像制作の対象ではありません。

## 4. 一人称の腰だめ・ADS（暫定規格：1774×887・承認待ち）

> この章は承認待ちです。1774×887 は暫定の規格で、試作画像を評価する前には正式に確定しません。承認されるまで、腰だめと ADS の制作は始めないでください。

### 4-1. 共通

| 項目 | 規格（暫定） |
|---|---|
| 最終出力 | **1774×887 画素**、PNG、RGBA 8ビット、背景は透明、アルファは0か255 |
| ドットの格子 | 最終出力では、**4×4 画素が1ドット**です。格子は、画像の左上 (0, 0) から4画素ごとにそろえます。どの4×4のます目の中も、同じ色・同じアルファにします |
| 高解像度の原本 | 残してかまいません。最終出力とは別のファイルで納品します。原本の作り方と縮小のしかたは、4-2 に従います |
| 端 | 上端は、腰だめ・ADS とも透明です。腕と袖は、画像の下端の外へ続きます。右端と左端の扱いは、4-4・4-5 に従います |

### 4-2. ドットの形を保つ作り方（高解像度の原本と縮小）

1774×887 は4で割り切れません（1774÷4＝443.5、887÷4＝221.75）。そのため、高解像度の原本を半端な倍率（例：2400×1200 を 0.739倍）で縮小すると、ドットの幅が3〜5画素にばらつき、輪郭がゆがみます。縮小した後でアルファを0か255にそろえるだけでは、この崩れは直りません。**この方法（半端な倍率の縮小と、アルファの2値化だけ）は使いません。** 最近傍法で縮小しても同じです。

**方法A（推奨）：ドット単位で描いて、整数倍に拡大する**
1. 1画素を1ドットとして、**444×222 画素**の原本を描きます。
2. 最近傍法（補間なし）で、ちょうど**4倍**に拡大します（1776×888）。
3. **右端の2列と下端の1行を切り落として**、1774×887 にします。
   - 切り落とす場所は、画面の外か、透明な場所です（4-3）。
   - そのため、格子は左上 (0, 0) にそろったままです。

**方法B：高解像度の原本を残す場合**
1. 原本は、**整数の大きさ N 画素のドットの格子**で描きます。
   - N は5以上の整数です。
   - 原本の大きさは 444N×222N です（例：N＝6 なら 2664×1332）。
2. 原本を、N×N のます目ごとに1つの色に置き換えて、444×222 にします。
   - **色：** ます目の中の不透明な画素で、いちばん多い色を選びます。
   - **アルファ：** ます目の画素の半分以上が不透明なら255、そうでなければ0にします。
   - 平均・バイリニア・バイキュービック・ランチョスなどの補間は使いません。
3. その後は、方法Aの手順2・3と同じです。

**格子がそろっていない原本の場合**
- 例えば、ドットの大きさや位置が一定でない生成画像です。そのまま縮小しないでください。
- 先にドットの大きさと位置を測って格子を復元し、方法Bの手順2でます目ごとに色を選びます。
- 格子を復元できない場合は、作り直しを依頼します。

**確認のしかた**
- 最終出力を、左上から4×4のます目に分けます（右端と下端のます目は 2×4・4×3・2×3 になります）。
- どのます目も、1つの色と1つのアルファでできていることを確かめます。
- この確認の道具は、まだありません（7-2）。

**既存の画像との違い**
- 既存のライフルの腰だめ・ADS は、この方法では作られていません（0.739倍に縮小した画像です）。実測では、同じ色が1画素だけで終わる所がいちばん多く、正確な4画素の格子にはなっていません。
- 既存の画像は承認済みなので、変えません（方針8）。
- 新しい画像のほうが輪郭がきれいに見える可能性があります。見た目の差は、試作画像で評価します。

### 4-4. 腰だめ（hip）

既存の腰だめの構図（1672×941）を、1774×887 のキャンバスに右下をそろえて移した目安です（x＋102、y−54）。

## 5. 武器ごとの制作指示

### 5-1. ショットガン（`weapon.shotgun.*`、武器ID `proto_shotgun`、メイン武器）

- **形：** 1980年代のポンプ式。管状の弾倉が銃身の下にあり、ポンプ式のフォアエンドがあります。照星は、銃身の先の丸いビーズです。スコープは付けません。
- **色：** 暗い鋼の銃身と機関部。フォアエンドと銃床は、木か黒い合成樹脂です。
  - 木の場合は、木の部品を色替えの対象にします。
  - 黒い樹脂の場合は、灰色と区別できる1つの系統にまとめます。
- **側面図：** 長い銃です。幅は1150〜1240画素が目安で、左右に100画素以上の余白を取ります。
- **腰だめ：** 右手で握りを持ちます。フォアエンドに左手を添えてもかまいません。太い銃身が、照準の方向へ向かうようにします。
- **ADS：** 銃身の上のビーズを、照準の点 (887, ≈388) に置きます。照門は、溝か小さな切り欠きです。
- **避けること：** 銃身を切り詰めた極端な形、ドラム型の弾倉、未来的な形。

### 5-2. ハンドガン（`weapon.handgun.*`、武器ID `proto_handgun`、サブ銃の枠専用）

- **形：** 角ばった9mmの自動拳銃です。スライドとアイアンサイト（白い点は任意）があり、握りの中に弾倉があります。
- **色：** 暗い鋼のスライドと、黒い握りです。色替えの対象（例：握りかフレーム）を、1つの系統にまとめます。
- **側面図：** 小さい銃です。幅850〜1000、高さ450〜550画素が目安で、キャンバスの中央に置きます。
- **腰だめ（例外）：** 両手で持ちます（右手で握り、左手を添える）。銃が小さいので、手と腕の割合が大きくなります。画面の右下に寄せ、照準の場所を空けます。
- **ADS（例外）：** 両腕を前に突き出して構えます。照門と照星を一直線に並べ、照星の先端を照準の点に置きます。両手の手首と袖は、下端から出ます。
- **避けること：** 特定の実在の拳銃とそっくりにすること、リボルバー、伸ばした銃身。
- **追記（2026-11-05、D-075）：** 腰だめの袖とグローブは、承認済みのハンドガンの ADS と同じ茶色のデザインにします（2章の「オリーブ色の迷彩の袖」は、ハンドガンについてだけ置き換え）。銃は側面図と同じ形、3/4の視点で銃身を左上へ約30°。制作の指示は受け渡し用フォルダの `HANDGUN_HIP_BRIEF.md`。

### 5-3. LMG（`weapon.lmg.*`、武器ID `proto_lmg`、メイン武器）

- **形：** 軽機関銃です。二脚は畳んだ状態にします。
  - 大きな箱形の弾倉か、ドラム型の弾倉
  - 太い銃身と、放熱用の穴のある覆い
  - 持ち運び用の取っ手
  - アイアンサイト
- **色：** 砂色の部品と暗い鋼です（ライフルと同じ系統）。砂色の部品を、色替えの対象にします。
- **側面図：** 長い銃です。幅1150〜1240画素が目安で、左右に100画素以上の余白を取ります。二脚と取っ手が欠けないようにします。
- **腰だめ：** 右手で握りを持ち、大きな弾倉が見える角度にします。重い銃なので、腕が少し下がっていてもかまいません。照準の場所は空けます。

- **避けること：** 弾帯が画面いっぱいに垂れる描き方、展開した二脚。

### 5-4. EPIC SMG（`weapon.epic_smg.*`、武器ID `proto_epic_smg`、メイン武器）

- **形：** 既存の SMG の系統（箱形の機関部と針金の銃床）を元にした試作品です。

  - 手描きの白いマーク（文字や数字にしない）

- **既存の SMG との違い：** 通常の SMG（既存）とは別の武器です。ひと目で区別できるようにしてください（試作品の印・表示灯・形の違い）。
- **側面図：** 幅1100〜1240画素が目安です。
- **腰だめ・ADS：** 既存の SMG の構図に合わせます。ADS では、照星の先端を照準の点に置きます。
- **避けること：** ネオン、光る線、ホログラム、未来的な曲面、SF 風の形。

### 7-5. 座標と Unity の表示処理の対応（2026-11-04 にコードを読んで整理。画面では未確認）

| 仕様の項目 | Unity での扱い |
|---|---|
| 画像の画素と画面の大きさ | 配置ファイルの `screenHeightPixels` で決まります（腰だめは1045、ADS は772）。`PixelWeaponArt` は、1単位あたりの画素数を `screenHeightPixels ÷ (2 × tan25°)` にします。視点用のカメラは、縦の視野が50°で、画像は z＝1 に置かれます |
| 腰だめの基準の位置 | `PixelWeaponArt.ApplyHip`。16:9（`referenceAspect`）の画面で、画像の右下を画面の右下に合わせ、`offset` (0, −0.05) だけ下げます。ピボットは `muzzle` ですが、画像の置き場所は `muzzle` の値に左右されません。`muzzle` は、銃口炎の位置にだけ効きます |
| 横長の画面 | `WeaponViewModel`。`hipRightEdgeFollow` 1.0 なので、画像は画面の右端の動きにそのまま付いていきます |
| 4:3 の画面 | `hipRightEdgeFollowNarrow` 0 なので、画像は動きません。`hipScaleAt4x3` 1.0 なので、縮みもしません |
| 全武器に共通の移動 | `WeaponViewModel.HipShiftLeft`：画面の高さの5%だけ左へ動かします。そのため、画像の右端が画面の中に見えます。`HipShiftDownAt`：画面の高さの9%に加えて、横長の画面では最大5%（4:3 で0、2622×1206 より横長で5%）下へ動かします。ADS は動かしません |
| 腰だめから ADS へ | `hipToAds` (0, −0.2)。腰だめの画像は、下へ動くだけです |
| ADS | `PixelWeaponArt.ApplyAds`。ピボットは `aim`（照星の先端）で、画面の中央に来ます。`muzzle` は銃口炎の基準で、`hold` は反動とリロードで回る中心です |
| 一時的な動き | 歩きの揺れ・反動・リロード・持ち替えで、画像は一時的に動きます。4-3 の座標は、静止しているときの値です |

- 照星の先端の y（386〜390）は、配置ファイルの `aim` で画像ごとに合わせます。ずれても表示はできますが、4-3 の映る範囲が変わるので、目安を守ります。

- **前の版の誤り：** 2026-11-02 の版は、`HipShiftLeft` と `HipShiftDownAt` を計算に入れていませんでした。そのため、照準の点を (845, 309)・(638, 309) としていました。これは誤りで、正しくは 4-3 の値です。

**追記（2026-11-05、D-074）：オンラインの表示**
- オンラインの一人称と観戦は、`OnlineWeaponView` が、オフラインの `WeaponViewModel` と同じ `WeaponViewPresenter`（配置・反動・リロード・持ち替え・クロスフェード・銃口炎・発光の重ね）で描きます。視点用のカメラ（縦の視野50°）を、使っているカメラの上に重ねます。

## 付録B. ハンドガンの側面図の制作指示（画像制作チャットに渡す確定版、2026-11-04）

> 画像制作チャットには、この付録Bだけを渡します。上の各章は、渡しません。

### 依頼

ゲーム「DEADLOCK: Since 1988」の武器画像を1枚だけ作ってください。**ハンドガン（サブ銃）の側面全体図**です。

### 必ず守る規格（1つでも外れると受け付けられません）

| 項目 | 規格 |
|---|---|
| 形式 | PNG（壊れていないこと） |
| 解像度 | **1440×800 画素ちょうど** |
| 色形式 | RGBA、各チャンネル8ビット（PNG のカラータイプ6） |
| 背景 | 透明 |
| 外周 | 外周1画素は、すべて完全に透明にします（銃がキャンバスの端に触れないこと） |
| 内容 | 銃が描かれていること |

### 向きと構図

- 真横から見た図です。斜めや上からの図にしないでください。
- **銃口が左、握りが右下**を向くようにします。
- 銃の全体を描きます。部品や輪郭が欠けないようにします。
- キャンバスの中央付近に置きます。
  - 大きさの目安は、幅850〜1000画素、高さ450〜550画素です（握りの下端まで含めて）。
  - 上下左右に、それぞれ100画素以上の透明な余白を取ります。
- 縦横比を変えて引き伸ばさないでください。

### 画風（基準：既存の SMG の側面図と、ライフルの素材）

- レトロ FPS 向けの 2D ピクセルアートです。金属や樹脂の質感を、ドットの形と陰影で表します。
- ドットの粗さは、既存の SMG の側面図と同じくらいにします。
- 太い暗い輪郭（2〜3ドット）と、段階的な陰影（材質ごとに4〜5段階が目安）を使います。
- **使わない表現：** ぼかし、グラデーション、ノイズ、アンチエイリアス、光のにじみ、写真のような質感。
- アルファは、0（完全に透明）か255（完全に不透明）にします。半透明の縁は作らないでください。
- 色は sRGB の前提で描き、ICC プロファイルは埋め込みません。
- 暗い背景でも明るい背景でも、形が読めるようにします。

### デザイン（案）

- 1980年代の軍用の雰囲気の、角ばった9mmの自動拳銃です。特定の実在の拳銃にそっくりにしないでください。
- 部品：
  - スライド
  - アイアンサイト（照門と照星。白い点は付けても付けなくてもかまいません）
  - トリガーとトリガーガード
  - 握りの中に入った弾倉（底が少し見える程度）
- 色：
  - スライドは暗い鋼、握りは黒です。
  - 色替えの対象にする部品（例：握りかフレーム）は、1つの色の系統でまとめます。スライドの暗い鋼とは、はっきり区別できるようにします。
  - その境目には、暗い輪郭を入れます。
- 付けないもの：
  - ライト、サイレンサー、光学照準器などの付属品
  - リボルバーの形、伸ばした銃身、未来的・SF 風の形

### 入れてはいけないもの

- 文字、型番、ロゴ、刻印の文字や数字、透かし
- 背景、床、地面、影
- 手や腕
- 武器の名前・レアリティ・性能を思わせる表示。どれもまだ決まっていません
