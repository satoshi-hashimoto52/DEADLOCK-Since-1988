### 3-3. 一人称（腰だめ・ADS）：新しい規格の案（未定義だったもの）

今のライフル・SMG の実際の画像に合わせる。**機械検査のカテゴリを AssetPipeline に足すかどうかは、ユーザーの判断。**

| 項目 | 腰だめ（`weapon_fp_hip` 案） | ADS（`weapon_fp_ads` 案） |
|---|---|---|
| 解像度 | 1672×941（ライフル・SMG と同じ） | 1774×887（ライフル・SMG の実際の画像と同じ）。代案：2400×1200 で描いて縮小（ライフルの制作依頼の方式） |
| 形式 | PNG、RGBA 8ビット。アルファは0か255が望ましい（柔らかい場合は2値の派生画像 `*_opaque.png` を作る。原本は残す） | 同じ |
| 背景 | 透明 | 透明 |
| 向き・構図 | 右手で持つ。銃と両手（グローブ）・袖を1枚に描く。画面の右下に置き、腕と銃床は下端・右端の外へ切れて続く。画面中央（照準）を空ける | 両手で構えて覗き込む。**フロントサイトの先端が画面中央**（弾の方向）。袖は下端から出る。下端と左右に、反動・リロードで動く余白 |
| ハンドガンの例外 | 両手持ち（右手で握り、左手を添える）。銃が小さいので、腕と手の占める割合が大きい。画面の右下に寄せる | 両手で前に突き出し、照門と照星を一直線に |
| 大きさ | ドットの大きさ（1ドット≒4画素）と輪郭の太さを、ライフル・SMG と同じにする | 同じ（ADS の輪郭が腰だめより太く見えるのは、既知の差として許容されている） |
| 一致 | 腰だめとADS が同じ銃に見えること（D-041） | 同じ |
| レイヤー | 1枚。色替え用に、銃の本体とグローブ・袖の境に黒い輪郭 | 同じ |
| 配色 | 1章の画風。グローブ・袖は既存と同じ色（スキンの領域図が同じ規則で作れる） | 同じ |
| 登録後の作業（こちらで行う） | 配置ファイル（銃口の位置、持ち手の位置、画面の高さに当たる画素数）、領域図、`WeaponArtDefinition`（`WeaponArtRegistry` の `candidates`） | 配置ファイル（照準の位置、銃口炎の位置） |
| 確認方法 | ユーザーの目視（明暗の背景、腰だめとADS が同じ銃か）。Unity の3つの画面比（16:9、iPhone の横長、iPad 4:3）での配置。実機はユーザーの確認 | 同じ。フロントサイトが画面中央に来ること |
