## 2. 反動設定仕様（検討案）

反動による**照準の移動**と弾の**集弾性／拡散**は独立して管理する。反動の方向は縦・横・斜め・複合を選び、適用する上下／左右方向と強度を指定する。

| パラメータ | 候補 | 用途 |
|---|---|---|
| `recoilAxis` | Vertical / Horizontal / Diagonal / Mixed | 縦・横・斜め・複合 |
| `recoilVerticalDirection` | Up / Down / None | 上下の指定。通常は上方向、下はテスト用途 |
| `recoilHorizontalDirection` | Left / Right / Alternating / None | 左・右・左右交互 |
| `recoilStrength` | Weak / Medium / Strong | **3段階** |
| `recoilKickDegrees` | 度/発（未決定） | 基準角度 |
| `recoilHorizontalRatio` | 0〜1（案） | 斜め方向の横方向成分 |
| `recoilPattern` | Fixed / Alternate / Seeded（案） | 毎発固定・交互・再現可能パターン |
| `recoilRecoverySeconds` | 秒（未決定） | 反動回復時間 |
| `adsRecoilMultiplier` | 倍率（未決定） | ADS時の反動の係数 |

方向例：上、下、左、右、左上、右上、左下、右下。上下・左右交互も設定可能とする。方向と軸の矛盾する組合せはUIで無効化する。

強さに対する**仮の係数**：弱=0.7、中=1.0、強=1.4。内部の基準角度と乗算する方式は提案であり、正式決定ではない。反動蓄積上限、視点反動と武器スプライトの揺れの違い、復帰の速度、オンライン対戦での再現性は実装前に検討する。

## 3. 距離によるダメージ補正（検討案）

武器ごとに距離mと威力倍率の**複数制御点**を設定し、制御点間を線形補間する初期案。

`基礎ダメージ = 武器の基本威力 × DamageMultiplier(発射点から命中点までの距離)`

| 距離 | rifle_A（倍率） | smg_A（倍率） |
|---:|---:|---:|
| 0m | 1.00 | 1.00 |
| 10m | 1.00 | 1.00 |
| 25m | 1.00 | 1.00 |
| 40m | 0.92 | 0.70 |
| 60m | 0.84 | 0.53 |
| 80m | 0.72 | 0.41 |
| 120m | 0.60 | 0.30 |

- 制御点は距離の昇順で重複不可。倍率0〜1を初期の編集範囲とする案。
- 最大到達距離超過は減衰とは独立して命中不可／ダメージ0とする。
- UIは制御点の表編集と折れ線グラフの両方を想定する。
- 被弾部位／防具／端数処理／弾道の経路長は未決定。既存のホスト権威の命中処理への適用順序を設計すること。
- 近距離・中距離・遠距離の初期プリセットは任意。ただし武器ごとの数値はユーザー採用まで未承認。

## 4. 調整専用ブランチ／プロファイルの運用

検討・試射用ブランチ：`feature/weapon-balance-lab`  
統合対象ブランチ：`feature/integration-smg-dungeon`

1. 統合ブランチの確定済みコミットを起点に検討ブランチを分岐。現在のローカル作業者の未コミット変更に触れない。
2. 武器定義と反動・減衰をデータプロファイル（例：Unity ScriptableObject）で管理する**設計**を検討。現行アセットを上書きせず試験用定義を作る。
3. 射撃場の開発者用UIで武器・反動方向と3段階強度・距離補正・試射結果を比較。調整結果は製品版セーブに混入させない。
4. 採用候補の数値セットを一意に記録し、試験結果と関連づける。
5. **ユーザーが採用した数値だけ**をコード変更とともにプルリクエストで統合ブランチへ反映。直接の自動マージ・pushはしない。
6. ローカル作業が必要になったら専用git worktreeの利用を検討。ブランチとworktreeは別であり、ブランチだけではアプリ内の調整UIは提供されない。
