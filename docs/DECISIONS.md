| D-010 | 銃に加えてサブの近接武器を持つ |
| D-011 | 近接武器の性能差は小さくし、威力・射程範囲の微調整にとどめる |
| D-012 | 銃のリロード、弾薬、射程、弾速を詳しく設計する |

| D-014 | 武器カスタムは武器種ごとに解放する |

| D-016 | 予備弾増加は開始時の予備弾数と携行上限を増やす |
| D-017 | ガチャは100ポイントで単発、1,000ポイントで11連。11枠中1枠が確定枠 |
| D-018 | デッドラインの通常報酬は生存者1位10pt、2位5pt、3位3pt。4位以下・死亡は0pt |
| D-019 | 特殊イベント・ボス討伐には専用報酬を設ける |
| D-020 | 実装はローカルのClaude Codeが担当。チャットで仕様・作業指示を作る |
| D-021 | 当面PublicのGitHubリポジトリで管理。公開設定は後で変更可能 |
| D-022 | 表現・操作感の参考はProject Warlock（レトロ表現）とCall of Dutyシリーズ（ADS・射撃の手応え）。参照範囲はGAME_SPEC.md 11.4 |
| D-023 | 開発用Unity EditorはUnity 6000.3.23f1、URPテンプレートから作成する。パッケージの正確なバージョンはdocs/DEVELOPMENT.mdに記録する。iOS下限・対象端末は未決定（Q-001／Q-002） |
| D-024 | 開発用リポジトリはUnityプロジェクトをリポジトリ直下に置く。仕様書の初版フォルダは別途保持する。試作実装は作業ブランチで行い、mainへの自動マージはしない |
| D-025 | ゲーム画面は横向き。左右どちらのLandscapeにも対応し、縦向きは許可しない（2026-10-19） |
| D-026 | プレイヤーの移動操作にジャンプを含める（2026-10-19）。高さ・空中操作量は暫定値 |
| D-027 | 立ち・しゃがみ・伏せの3姿勢。姿勢変更に短い移行時間。頭上の空間が足りなければ姿勢を戻さない。しゃがみ・伏せ中のジャンプ入力は立ち上がり要求（2026-10-19） |
| D-028 | ダッシュは立ち状態のみ。しゃがみ・伏せでも射撃・リロード可能（2026-10-19） |
| D-029 | 銃とサブ近接武器を持ち替え、近接武器でターゲットへ攻撃できる。近接攻撃は壁越しに当たらず、1回の攻撃で同じ対象へ重複ダメージを与えない（2026-10-19）。数値・操作割り当ては暫定 |
| D-030 | ダッシュからのスライディングを追加する。立ち・接地・ダッシュ中・十分な実速度・再使用待ち終了が条件。開始方向へ減速しながら滑り、しゃがみで終わる（頭上が足りなければ既存の判定に従う）。無敵・ダメージ・弾薬効果なし、ジャンプ取り消しなし、連打・押しっぱなしで再発動しない。PCはダッシュ中のC、モバイルはダッシュ中の姿勢ボタン（2026-10-20）。時間・減速・再使用待ちは暫定値 |
| D-031 | タッチ操作のレイアウトをゲーム内（メニュー → 設定 → 操作レイアウト）で変更でき、端末に保存する。実際のゲーム画面に重ねて編集し、編集中はゲーム入力を止める。Safe Areaに対する相対座標で保持する（2026-10-20） |
| D-032 | メニューを開いたときは、その端末のプレイヤー入力だけを止める。ゲーム全体の一時停止は1人用のオフライン練習でのみ行い、将来のオンライン対戦では全体を止めない（2026-10-20） |

## 3. まだ採用していない具体案

### スコアの仮案

| 行動 | 提案値 |
| --- | ---: |
| 通常モンスター討伐 | 10 |
| 強敵討伐 | 50 |
| 対戦相手の撃破 | 100 |
| 対戦相手へのアシスト | 最大50 |

上記は未承認。ガチャポイントとは別の試合内スコアであり、直接通貨に変換しない。
生存者優先、同点時は対人与ダメージ→対モンスター与ダメージ→同順位という案も未確定。
BOTの入賞を含めて繰り上げしない案は、初期実装に自動採用しない。

### 武器カスタムの旧候補

- 銃口：サプレッサー／コンペンセイター。
- 操作系：ADS用グリップ／安定化グリップ。
- 3枠構成、熟練度で6候補を選択解放する案は未確定。
- 弾倉は最新合意の2タイプを優先し、高速交換マガジンを確定仕様に混入させない。
- 増加量の30→40発、予備上限90→150発などは説明用の例。

## 5. 今後の記録方法

追加決定は日付・決定内容・理由・影響範囲を記載し、GAME_SPEC.mdへ反映する。
未決定項目を確定したら、そのIDに決定先を記し、未決定のまま残さない。
会話上で提案しただけの数値を、承認済みとして扱わない。
