## 4．完成ADSの差し替え手順（自動処理で上書きさせない）

1. 完成画像を `Assets/Game/Art/Weapons/Rifle/rifle_ads_approved.png` に置く（2400×1200、透明背景）。
2. `Assets/Game/Art/Weapons/Rifle/rifle_ads_approved.placement.json`（用意済み）の `aim`（狙点）・`muzzle`（銃口）を、完成画像で実際に描かれた位置に合わせる。寸法を変えた場合は `screenHeightPixels`（画面の高さに当たるpx）も直す。
3. シーン生成（DEADLOCK → Prototype → Rebuild Firing Range）。`PixelWeaponArt` が取り込み設定（Point・非圧縮・ピボット＝狙点）とADSの銃口位置を設定する。ベイク（`Art/Generated`）・`draw_weapons.py`（`Art/Weapons` 直下のSpr_*のみ）・シーン生成は `Rifle/` の画像を書き換えない。
4. 確認：ADSで狙点が画面中央にあること、発砲エフェクトの位置、リロード中に画面の隅で切れ目が出ないこと。この取り込みの経路は、ガイド画像を仮に置いて「狙点の十字が画面中央（2.6px以内）、発砲エフェクトが基準点」になることを確認済み（確認後に仮の画像は削除）。

## 6．残る調整点

- **ADSの制作**（上記ガイド）。完成するまでADSは旧ライフルの暫定画像で、腰だめから覗くと銃が変わって見える。
- 腰だめからADSへの移行中（構え0.45〜0.62）に、腰だめの絵が中央へ動く。iPhoneでは移行の途中で画像の右下の角（銃床の下24px）が一瞬画面内に入る可能性がある（静止画では未確認）。
- 標準の操作配置では、ジャンプ・FIRE・ADSボタンが銃の上に重なる（UIは手前に描かれる）。透過率の設定や配置の変更で調整可能。
- 元画像の不透明部分のアルファ253（約99%）と縁の半透明のにじみ。必要なら書き出し元での再出力。
- 銃口炎の大きさ（0.4）と、反動・リロードの動きの量は旧ライフルの値のまま（大きな絵に合うかは人の確認が必要）。
- 実機（iPhone・iPad）での見え方は未確認（今回は新しい実機ビルドを入れていない）。
