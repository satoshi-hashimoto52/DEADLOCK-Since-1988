# 手元武器の確認資料（2026-10-20）

**状態：ライフルの画風はユーザー未承認。** ここにある「現在」の絵は暫定版（D-041）。ライフルの腰だめ・ADSは3Dベイクを縮小・減色したもので、目標の画風には達していない。ナイフ・手・銃口炎はコードで描いた手描きの試作。

確認した点（Editorの描画での目視）：

- 欠け・位置ずれなし。腰だめ・ADS・ナイフとも、腕と袖は画面の下端・右端から入り、リロードで最も下げて傾けた状態でもスプライトの端（切れ目）は画面内に出ない。
- 銃口炎は腰だめ・ADSとも銃口の位置。ADSのフロントサイト先端は画面中央（変更前と同じ位置）。
- 暗い背景では上側の明るい縁、明るい背景では暗い外周線で形が読める。
- リロードの動き（下げて傾ける）は変更前と同じ量で小さめ。専用のリロードの絵（弾倉の抜き差し）はない。
- 腰だめの銃の形・手の形は変更前の簡易3Dモデルそのまま（直方体の組み合わせ）。質感の描き込みはない。

## 参考画像について（2026-10-20の作業指示）

- 「現在画像」（iPhoneの画面）と参考画像1枚（2丁拳銃を両手で構えるドット絵のFPS画面）は読めた。**指示にあった参考画像2枚のうち、もう1枚はこのセッションには届いていない**ため参照していない。
- 参考画像は見た目の方向性の確認にのみ使い、画像そのもの・その絵柄の複製は素材に使わない。
- 参考画像から読み取れる、目標に関係する特徴（作者の判断を含む）：手元が画面の下部の大きな面積を占める／銃・手の輪郭が太く、色数を絞った段階的な陰影で金属・布の違いを描き分けている／グローブの指や袖のしわがドットの形で描かれている／金属の上面に明るい縁がある。

## 画像制作AI・外部制作への依頼文（案）

以下は実データ（`Assets/Game/Art/Weapons/pixel_weapons.json`、`Assets/Game/Data/WeaponView_ProtoRifle.asset`、`MeleeView_ProtoKnife.asset`）に合わせた依頼文。寸法・基準点は `guide_*.png` と同じ。

```text
一人称視点のシューティングゲーム用の、手元の武器のピクセルアート（ドット絵）を制作してください。

【画風】
- 背景の3D（低解像度のレンガ・タイル）より細かく描き込んだ2Dピクセルアート。
- 金属（銃本体）・樹脂（ハンドガード）・革のグローブ・布の袖の質感を、ドットの形と陰影の段階だけで描き分ける。
- 1素材あたり4〜5色の固まった陰影。ぼかし・グラデーション・ノイズ・アンチエイリアスは使わない。
- 外周に暗い輪郭線、上側（光の当たる面）に明るい縁。暗い背景・明るい背景のどちらでも形が読めること。
- 既存作品のキャラクター・銃・絵柄をそのまま写さないこと。

【共通の設定】
- 武器：アサルトライフル（金属の機関部とレール、フロントサイト、リアサイトのリング、FDE（砂色）の樹脂ハンドガード）。腰だめとADSで同じ銃・同じ配色にする。
- 手：濃い茶色の革グローブ。袖はオリーブドラブの布。
- 配色の目安（暗→明）：
  金属 #282D36 #424A56 #626D7C #9CA8B8（輪郭 #101216）
  ハンドガード #54422C #745E40 #927954 #BEA476
  グローブ #3A2C20 #56422E #745A3E #A0805A（手のひら側のパッド #403C38 #58544E）
  袖 #3C4626 #566436 #708046 #96A860
- 背景は透明（PNG、アルファ付き）。半透明のドットは使わない（完全不透明か完全透明）。

【1】腰だめ（Spr_PixelRifleHip.png）
- キャンバス 287×160ドット。画面の右下に置く絵で、キャンバスの右端＝画面の右端、下端＝画面の下端。
- 銃口はキャンバスの左上、座標(6, 11)付近。銃はそこから右下へ伸び、機関部・銃床は右端・下端の外へ続く形にする。
- 左手（グローブ）がハンドガードを下から握り、手首（グローブと袖の境）は座標(55, 127)付近、袖は下端の外へ続く。
- 画面中央（照準）はキャンバスの外の左上（-33, -20）にあり、銃・手をそこへかけない。
- 右端・下端は透明の余白を作らず端まで描き切る（動いたときに切れ目が見えないように）。左上も余白なし。

【2】ADS（Spr_PixelRifleAds.png）
- キャンバス 134×225ドット。フロントサイトの先端を座標(63, 45)に置く（ここが画面中央＝弾の方向）。
- リアサイトのリングの中にフロントサイトが見える構図。銃口は(63, 80)付近（銃口炎がここに出る）。
- キャンバスの下端＝画面の下端。腰だめと同じ銃・同じ配色。手（グローブ）を描く場合は下端の外へ続く形にする。

【3】ナイフと手（Spr_PixelKnife.png）
- キャンバス 186×169ドット。刃先が左上、ナイフを握った手（グローブ）が右下。握りの基準点は座標(90, 134)。
- 袖は右下の端の外へ続く。左上に6ドット程度の透明の余白。

【4】銃口炎（Spr_PixelMuzzleFlash.png）
- 48×48ドット、中央が銃口。明るい芯と光条。2〜3コマ（同じ大きさ）あると良い。

【あると良い追加素材】
- リロード（弾倉を外す・入れる）の手のコマ、ナイフの振りのコマ、持ち替えのコマ、発砲時の反動のコマ。
  いずれも各キャンバスと同じ寸法・同じ基準点。
```
