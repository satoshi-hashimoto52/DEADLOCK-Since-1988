ゲーム本編の開発を進めるため、2つの作業ブランチの変更を、1つの開発版で使えるようにまとめた。

- 統合ブランチ：`feature/integration-smg-dungeon`。別のworktree（`../DEADLOCK-Since-1988-integration`）で作業した。
- 元のブランチ：
  - `feature/network-prototype`（SMG、`4888000`）を基点にした。
  - `feature/dungeon-test-field`（遺跡・ミニマップ、`7b6045b`）を、マージコミットで取り込んだ。
- 元の2ブランチとmainは変更していない。
- 各worktreeの無関係な未コミット変更・未追跡ファイルは、移動も削除もしていない（統合のworktreeには入っていない）。
- ホーム背景の素材（制作中）は、今回の統合に含めていない。

## 2. 統合後に使えるもの

- 移動：射撃場、トレーニング、遺跡（テスト）。
- 銃のテスト選択：射撃場・トレーニング・遺跡で、ライフルとSMG（候補）を切り替えられる。
  - 選択は保存しない。再挑戦では保ち、アプリを再起動するとライフルに戻る作り。
  - SMGの性能は、検証用にライフルの値を写したまま（正式な性能は決めていない）。
- ナイフとの往復、射撃、ADS、リロード、スキン（SMGの武器スキンと手・腕のスキンは別々）。
- 遺跡のミニマップ：表示のON／OFF、位置と大きさの編集と保存。
- 遺跡側で直した性能ログ（移動距離・攻撃回数など）と、NavMeshの初期化（ゾンビのAgentを無効で保存し、開始時に有効にする）。

## 3. 保存値

- 設定のキーは、両方のブランチのものをそのまま使う。新しいキーは足していない。
  - 操作レイアウト、ADS、FIRE、透過率、スキン、ミニマップの表示・位置・大きさ。
- 既存の保存値を初期化する処理は入れていない。
- 自動テストは、テストの前後で利用者の保存値を戻す作り。

- PlayMode：115件。最初の実行では114件が成功し、1件が失敗した。

  - 各行を書いた時点の位置と比べるように直した。関連の20件（ミニマップ、SMG、遺跡）を再実行し、すべて成功した。
  - PlayModeの全体を再実行し、115件すべて成功した。
- 追加したテスト：`SmgCandidateTests.Ruins_SmgFiresAndAims_RetryKeepsIt_MapEditStillWorks`。
  - 遺跡で、メニューからSMGに切り替えて、射撃とADSができる。
