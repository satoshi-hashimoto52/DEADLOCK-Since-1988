# SMG：ADS画像の制作依頼資料（2026-10-22、同日に依頼文を修正、Issue #2）

SMGのADS（照準を覗いた状態）の画像を、画像制作AIへ依頼するための資料。

- デザインの基準は、SMG候補v2の腰だめ（`Assets/Game/Art/Weapons/SMG/smg_hip_candidate_v2.png`、2026-10-22に制作基準として決定。`../README_design_review.md` の5章）。
- **ADS画像の生成、全体図の制作、ゲームへの組み込みは、まだ行っていない。** ゲームで表示する素材の正式採用は、配置と動作の確認の後に判断する。

## 1. 採用済みライフルADSの表示方式（SMGも同じ仕組みで表示する）

| 項目 | 内容 |
| --- | --- |
| 基準点 | 照星（フロントサイト）の柱の先端＝画像のピボット＝ゲーム画面の中央＝実際の弾の方向 |
| 大きさ | 画像の何ピクセルが画面の高さに当たるか（`screenHeightPixels`）で決まる。ガイドのキャンバスでは1044px。ライフルの腰だめは1045px（SMGの腰だめも同じ値を想定）なので、1ドット＝4px で描けば、腰だめとドットの大きさがそろう |
| 腰だめ → ADS | ADSの絵は、0.1単位（キャンバスで約112px）下からせり上がる。構えの進み具合が0.45〜0.62の間で、腰だめと入れ替わる（クロスフェード） |
| 動き | 反動、リロード（0.1単位下げて14°傾ける）、ダッシュの揺れ。画面の下の角に見えるのは、狙点の最大677px下まで。キャンバスは678px確保している |
| 取り込み | 元画像は保持し、アルファだけを2値にした派生（`make_opaque.py`）を表示する。配置ファイル（`*.placement.json`）に、狙点・銃口・持つ位置を、完成画像から読み取って書く |
| 参考 | ライフルのADSは、ガイド（2400×1200）の約0.739倍（1774×887）で届いた。手・銃の大きさの比率が保たれていたので、配置ファイルの `screenHeightPixels` を772にして使った。今回は寸法どおりに依頼する |

### 銃と手の大きさ（☆）

- ドットの大きさ：1ドット＝4px。黒い輪郭の太さは、腰だめ候補と同じ2〜3ドット（9〜11px）。
- 照門の耳の外側の幅：約224px（56ドット）。照星の耳の外側の幅：約72px（18ドット）。
- 手の大きさ：ADSは目に近い分、腰だめより大きく写る。左手の幅は300〜420px 程度。グローブ・帯・袖の模様の1ドットは、銃と同じ4px にする。

## 3. 腰だめと同じ銃に見えるための特徴

| 部位 | 腰だめ候補で確認できること | ADSでの扱い |
| --- | --- | --- |
| 銃口・銃身の先 | 短い銃身の先に、段の付いたナット（暗い鋼色） | 照星の台座の下に、ナットの縁が少し見える程度。ほぼ隠れてよい |
| 照星 | 前部ブロックの上に、左右2本の耳（U字形） | 2本の耳はそのまま。**中央の柱は推定**（腰だめでは耳の間が見えにくい）。柱の先端を狙点にする |
| 照門 | 機関部の後ろの上に、左右2本の耳が立つブロック。耳の間に小さな明るい点 | 手前に大きく。**開口が穴（ピープ）か切り欠きかは推定**。どちらでもよいが、開口の中心を狙点に合わせる |
| 機関部・上面 | 黒〜暗い灰色の箱形。上面は平らで、明るい縁取りのハイライト。側面に2本の長い溝 | 上面を平らな箱形で。側面の溝は、真後ろからはほぼ見えない（推定）。描く場合は控えめにする |
| 前部・後部の外装 | 前部ブロック（照星の下）、後部ブロック（照門の後ろ）、丸いボルト・つまみ | 外装は同じ黒〜暗い灰色。ボルト・つまみは、見える範囲で丸く少数 |
| 砂色の縦長の枠 | 機関部の左側面にある差し色 | 真後ろからは見えない（推定）。描かなくてよい |
| 弾倉・グリップ | 弾倉はグリップの前。グリップは右手で握る | 機関部の下にほぼ隠れる。右手の指の間に、グリップが少し見えてよい |
| 銃床 | 右側面に、折りたたんだワイヤーの枠（明るい縁の暗い鋼） | 右下に細く少し見えてよい。省略してもよい（推定） |
| 手・腕 | 茶色のグローブ、暗い灰色の手首の帯、オリーブの迷彩の袖 | 腰だめ候補と同じ配色・同じ描き方 |
| 画風 | 太い黒の輪郭、少ない段階の陰影、明るい縁のハイライト | 同じ。ぼかし・グラデーション・ノイズなし |

- 腰だめの画像から見えない部分（真後ろから見た幅・奥行き、照星の中央の柱、照門の開口の形、銃床のたたみ方）は**推定**。形は複雑にしない。
- 色替えの範囲を後で作るため、外装（機関部・前部・後部・ボルト・つまみ）と、固定色の部品（照星・照門・銃口・弾倉・グリップ・銃床）の間には、黒い輪郭を入れる。

## 5. 届いた後の手順（予定、今回は行わない）

1. 寸法、透明度、照準の位置、袖の切り口、画風を検査する（腰だめ候補と同じ方法）。照星の先端の実際の位置を測り、配置ファイルの `aim` に書く（指定との数pxの差は、ここで吸収する）。寸法が2400×1200でない場合は、`screenHeightPixels` を実寸の比率に合わせる（ライフルADSと同じ扱い）。
2. 表示用の派生と配置ファイルを作り、ゲーム外のプレビューで3画面比を確認する。
3. ユーザーが判断した後に、性能の仮定義・取り込み・ゲーム内の確認へ進む（全体図は別に依頼する）。
