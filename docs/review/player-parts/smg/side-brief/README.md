## 3. 装備画面での表示方法（提案）

`smg_side_display_proposal.png` に、装備画面の武器の欄（画像の枠 776×284）に入れたときの大きさを比べた。

| 表示のしかた | 倍率 | 銃の長さ | 欄の幅に対して |
| --- | --- | --- | --- |
| A：キャンバス全体（余白込み） | 0.355 | 327px | 42% |
| **B（提案）：標準の表示範囲だけ**（x 400〜1360、y 232〜712） | 0.592 | 544px | 70% |
| C（取付時の例）：取付部品の範囲まで広げる（x 120〜1360、y 160〜780） | 0.458 | 421px | 54% |

- 将来の部品のための余白をキャンバスに取ると、キャンバス全体を表示した場合に銃が小さくなる（A）。
- 提案：画像はキャンバスのまま保存する。装備画面では、武器ごとの「標準の表示範囲」を配置ファイルに書き、その範囲だけを欄に収める（B）。
  - 取付部品を付けたときだけ、範囲を広げる（C）。
  - 銃口の先端 (420, 360) は、表示範囲が変わっても同じ点を基準にする。
- 武器ごとに表示範囲を合わせるので、ライフルとSMGは、装備画面では実際の大きさの比とは違う大きさで見える。同じ縮尺で比べる画面が必要になったら、別の表示として考える。
- この案は、**取り込み時の検討案**として保持する。現時点では実装しない（今は画像全体を表示する）。

## 5. 届いた後の手順（予定、今回は行わない）

1. 寸法、透明度、向き、銃口の先端・銃身の中心線の位置、空白の範囲、画風を検査する。推定の部分（手で隠れていた所）がつながって見えるかを確認する。
2. 元画像は保持し、必要なときだけアルファを2値にした派生を作る。
3. 決定済みの範囲で、全体図の領域マップを作る（ライフルの全体図と同じ `make_image_regions.py`）。
4. 装備画面の表示範囲（第3章のB）を配置ファイルに書き、表示を確認する（Editor）。
5. 正式採用は、ユーザーが判断する。
