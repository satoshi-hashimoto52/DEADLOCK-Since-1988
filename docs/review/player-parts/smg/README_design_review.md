## 2. 色替え範囲の推奨（提案・未確定）

### 方針

採用ライフルと同じく、**銃本体の外装だけを武器スキンの対象**にする。
- 照準器・弾倉・グリップ・銃口などの機能部品は固定色にする。
- 黒い輪郭は、どの部品でも色を変えない（線の黒は領域に入らない）。
- 陰影は保たれる。今の方式は、描かれた明るさを残し、色相・彩度だけを置き換えるため。

| 部品 | 提案 | 理由（実際の絵から） |
| --- | --- | --- |
| 機関部（側面の2本の溝を含む） | **対象** | 銃の中心の外装で、面積が最も大きい。ライフルの外装（砂色の部分）に当たる |
| 前部ブロック（照星の下の上面と、側面の下側まで） | **対象** | 機関部とつながる同じ外装部品なので、暗く描かれた側面の下側も含める。提案範囲の画像では、すでに含まれている。色が変わらず残るのは、黒い輪郭の画素だけ |
| 後部ブロック（暗い下面を含む） | **対象** | 機関部の後ろの外装。右手の上まで続く暗い下面も、同じ外装部品として含める（2026-10-22に範囲を広げた） |
| 銃床の付け根の丸い部品（ボルト） | **対象** | 外装と一緒に色替えする。境界：この丸い部品を囲むヒンジ板（x 1380〜1452、y 650〜745）から右は銃床側で、固定色（`design_review_stock_boundary.png`） |
| 本体のボルト・丸いつまみ | **対象（推奨）** | 外装と一緒に色替えする。外装の上に付いた部品で、外装と同じ色に変わるほうがまとまって見える |
| 銃口・銃身の先（ナット） | 固定 | 金属の機能部品。ライフルも銃口部品は固定 |
| 照星・照門 | 固定 | 照準器。ライフルも固定 |
| 弾倉 | 固定 | ライフルも黒い弾倉は固定 |
| グリップ・引き金 | 固定 | ライフルも固定。大部分が右手に隠れる |
| ワイヤー銃床とヒンジ板 | **固定（推奨）** | 細い金属の枠と、その付け根の板。ライフルの銃床（砂色の外装）とは違い、機能部品として扱う |
| 側面の縦長の枠（砂色） | 固定 | 差し色。ライフルの赤い表示と同じ扱い |
| 黒い輪郭 | 固定 | 常に固定 |
| グローブ・手首の帯・袖（地色・迷彩） | **手・腕スキン**（武器とは独立） | ライフル・ナイフと同じ。武器スキンとは別に選ぶ |

### 提案範囲の作り方（再現できる）

## 3. 暗い外装の扱い

**基本案：標準の配色（黒〜暗い灰色）は維持する。**

既存の方式と試作色（武器 test_green：色相95°・彩度0.22）のまま、どの程度見分けられるかを確認した。

| 項目 | SMG（提案範囲） | ライフル（採用済みの範囲） |
| --- | --- | --- |
| 外装の明るさ（L\*の中央値） | 25 | 66 |
| 標準と test_green の色差 ΔE（CIE76）：10%点／中央値／90%点 | 9.5／**20.3**／29.4 | 22.0／**26.9**／28.3 |

- 目安：ΔE は2〜3で、並べると分かる程度。10を超えると、はっきり違う色に見える。
- SMGの中央値20.3は、ライフル（26.9）より小さいが、はっきり見分けられる大きさ。
- 実際の表示サイズ（`design_review_display_size_iPhone16Pro_1to1.png`）でも、試作色の外装は暗い緑として、標準の黒い外装と区別できる。照準器・弾倉・グリップは黒いまま残り、形も読める。
- 色はライフルより暗く出る。これは暗い配色のデザインによるもので、**不具合とは扱わない**。
- 視認性の問題は見つからなかったので、**対応は不要**と判断した。

参考：将来、明るい色のスキンが必要になった場合の選択肢（今回は行わない）。
- デザインの段階で、外装の一部に明るい塗装面を設ける（画像の変更）。
- 明るさの扱いを、スキンごとに指定できるようにする（共通シェーダー・スキン定義の変更が必要）。

## 4. 判断していただくこと

（2026-10-22 更新）2章の範囲を、ユーザーの指示に合わせて推奨案として整理した。前部ブロックの側面の下側は「暗くて見えないので固定」とはせず、同じ外装部品として対象に含める。提案範囲の画像（`design_review_region_proposal.png`）と比較画像は、この推奨案と同じ範囲で作られている。

1. **候補v2の形と配色を、SMGのデザインの基準にするか**：黒い本体、折りたたみのワイヤー銃床、グリップの前の弾倉、照星・照門。
2. **色替えの範囲**：2章の推奨案でよいか。
   - 外装：機関部、前部ブロック（側面の下側を含む）、後部ブロック。
   - ボルト・つまみ：外装と一緒に色替えする。
   - ワイヤー銃床：固定。
   - 黒い輪郭：保持する。
3. **暗い外装**：標準の配色を維持し、試作色が暗く出ることを許容するか（3章の基本案）。
4. 輪郭の太さの差（候補 9〜11px、ライフル腰だめ 6〜9px）を許容するか（前回の資料）。

判断の後に、ADS・全体図の制作依頼、正式の領域マップ、配置ファイルへ進む。どれも今回は保留している。
