# SMG：開発用のテスト選択への仮組み込み（2026-10-22、Issue #2）

SMGは、正式採用前の候補として扱う。通常の武器選択には加えていない。性能は、検証用にライフル相当の値を使った（SMGの性能を決めたものではない）。

## 1. 使う素材

- 腰だめ：`smg_hip_candidate_v2_opaque.png`（元画像 `smg_hip_candidate_v2.png` の2値化した派生）、配置 `smg_hip_candidate_v2.placement.json`。
- ADS：`smg_ads_front_sight_gap3.png`（照星の隙間を広げた比較候補。アルファは元から2値なので、そのまま表示）、SMG専用の配置 `smg_ads_front_sight_gap3.placement.json`。
  - フラッシュの位置は (887, 480)、倍率は 0.25。照準点は (887, 386)。
- 元画像の再探索・改名・再生成はしていない。

## 2. 組み込み

- 武器の定義：`Assets/Game/Data/Weapon_ProtoSMG_Candidate.asset`（id `proto_smg`）。
  - シーンを作り直すたびに、ライフルの定義から性能値をすべて写す（ライフル相当であることを保つ）。名前は「SMG CANDIDATE (RIFLE VALUES)」。
  - ライフルの定義（`Weapon_ProtoRifle.asset`）は読むだけで、変えていない。
- 一人称の絵の定義：`Assets/Game/Data/WeaponArt/WeaponArt_ProtoSMG_Candidate.asset`。
  - 登録リスト `WeaponArtRegistry` に新しく「候補（candidates）」の欄を作り、そこに入れた。通常の武器（weapons）とは分けている。取り込みの方法は同じ。
  - 作る手順：`SmgCandidateSetup`（エディターの処理）。
- 開発用のテスト選択：`DevGunSelection`。射撃場とトレーニングにだけ付けた（オンラインには付けていない）。
  - メニューに「銃（テスト用）：ライフル → SMG（候補）」のボタンを置いた。押すたびに切り替わる。
  - 切り替えると、弾倉は満タン、予備弾は初期値になる。リロード中とADSは解除し、引き金をいったん離すまで撃たない。
  - 選択はアプリを動かしている間だけ有効。シーンの読み込みと再挑戦では保つ。保存はしないので、保存値は変わらない。
- 銃の差し替え：`GunController.SetDefinition` を追加した。`WeaponViewModel` は差し替えに合わせて絵・フラッシュ・スキンを読み直す。
  - 領域マップのない銃に切り替えた場合は、描いた色に戻す。前の銃の領域マップを残さない。

## 3. スキン（領域マップ）

- 決定済みの範囲で作った（`README_design_review.md` の5章）。
  - 色替え：機関部、前部・後部の外装、ボルト・つまみ、銃床の付け根の丸いボルト。
  - 固定色：銃口、照星・照門、弾倉、グリップ・引き金、ワイヤー銃床とヒンジ板、砂色の枠、黒い輪郭。
  - 手・腕：グローブ、手首の帯、袖の地色・迷彩。
- 腰だめ：`Regions/Hip/`。提案時と同じ定義を、表示する派生画像に当てた。画素数は提案と同じ。
  - 武器の外装 44,265、グローブ 42,691、帯 8,340、袖の地色 44,314、袖の迷彩 31,118。
- ADS：`Regions/ADS/`。新しく定義を書いた。画像のマス目の切り出しから範囲を読んだ。
  - 色替え：照門の下の段になった台、左のつまみ、後部ブロックとその後ろの面。
  - 固定色：照門・照星、ワイヤー銃床の左右の棒。
  - 画素数：武器の外装 44,522、グローブ 33,361、帯 8,463、袖の地色 35,499、袖の迷彩 23,758。
  - ツールの検査（重なり、線の黒、範囲外）はすべて通った。
- スキン一覧に「SMG（候補）」を追加した。試作色は「色違い（試作）」で、ライフルと同じ緑の仮の値。手・腕のスキンは全武器で共通。
- 装備画面：SMGを持っているときは「SMG（候補）（横）　全体図は未制作（画像なし）」と表示する。ライフルの全体図をSMGとして出さない。SMGの全体図はまだ作っていない。

### 実機での確認手順（導入するとき）

1. 射撃場で、メニュー → 「銃（テスト用）」を押して、SMG（候補）に切り替える。
2. 腰だめ、ADS、射撃、反動、リロード、ナイフへの切り替えと戻りを、それぞれ確認する。
3. トレーニングでメニュー → 再挑戦を行い、SMGのままで、満タンの弾倉から始まることを確認する。
4. 装備・スキン（テスト用）で次を確認する。
   - SMGの「色違い（試作）」と、手・腕の「色違い（試作）」を切り替えて、腰だめとADSに反映されること。
   - ライフルの色が変わらないこと。
   - SMGの全体図が「画像なし」と表示されること。
5. 確認の後に、スキンを元の選択に戻す。銃の選択は保存されないので、アプリを再起動するとライフルに戻る。
