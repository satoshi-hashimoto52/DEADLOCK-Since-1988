## 2. 表示の確認（Editor の PlayMode、batchmode）

### 確認の方法

- 既存の表示コード（`PixelWeaponArt.Import` → `WeaponViewModel`、`GunController`）を変えずに使った。
- 配置ファイルは確認用に手で書き、ゲームには登録していない（下の3章）。
- 確認のためだけに、一時的な定義を作った（確認後に削除し、コミットしていない）。
  - 一時的な武器定義の性能値は、**ライフル（`Weapon_ProtoRifle`）の値をそのまま使った**。連射間隔・反動・リロード時間・ADSの視野角などがこれにあたる。
  - これは表示の確認のためだけの値で、**SMGの性能を決めたものではない**（Q-011 は未決定のまま）。
- 実寸で表示した。
  - 腰だめ：画面の高さ 1045 px あたり1枚（ライフル腰だめと同じ）。
  - ADS：画面の高さ 772 px あたり1枚（構図ガイドの 1044 × 0.739）。
  - 引き伸ばしや切り抜きはしていない。
- 画面サイズ：iPhone 16 Pro（2622×1206）、16:9（1920×1080）、4:3（2048×1536）。
- カメラと照明は射撃場の既定のまま。確認専用の設定は使っていない。

## 4. 見つかった課題

### 画像の修正が要るもの（判断はユーザー）

1. **中央ポストの左右の隙間が 1–2 px**。絵の1ドット（約 3 px）より細い。
   - 等倍の画面では読める。しかし、ポストと耳がつながって見えやすい。
   - はっきり分けたい場合は、画像側で隙間を1ドット以上に広げる必要がある。配置では直せない。
   - 直さずに採用することもできる。どちらにするかは未決定。
2. それ以外に、画像の修正が要る問題は見つからなかった：サイズ、アルファ、輪郭、ゴミ、欠け、手と袖の色。

### 配置で調整できるもの

1. ADSのマズルフラッシュの位置・大きさ。いまは照星の根元 (887, 430) に重なる。照星を隠したくなければ、muzzle を下げるか、フラッシュの倍率を変える。
2. 腰だめの muzzle と hold。画像から読んだ値で、いまの表示に問題は見えない。必要なら微調整できる。
3. 腰だめのフラッシュの倍率 0.4、hipToAds、リロードの下げ・傾き。どれもライフルの値で、SMGとしてはまだ決めていない。
4. ADSのドットの粗さ（772 と 1045 px の差）。screenHeightPixels を変えると照星の大きさと腰だめとのつながりも変わるため、ライフルと同じく現状のままとした。
