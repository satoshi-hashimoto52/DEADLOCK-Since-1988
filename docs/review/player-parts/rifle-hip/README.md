## B．部位の分類（`classification.png`・`classification_full.png`・`contact_A〜E.png`・`layers_overview.png`）

分け方（`Tools/pixelart/split_layers.py`、数値は定義ファイル）：

1. 黒い輪郭（全チャンネルが45未満）で区切られた塗りの範囲を「区画」として扱う（131区画）。
2. 区画の主な色がグローブの茶色・袖のオリーブ色で、**その手の範囲**（左：x 0〜1120・y 490〜941、右：x 1180〜1420・y 780〜941）にあれば、その手。それ以外は銃。色だけでは決めない（銃の中の茶色・オリーブ色の数画素の欠片は位置で銃になる）。
3. 手首の帯は銃の金属と同じ灰色なので色では分けられない。帯の区画を座標で指定（定義の `cellOverrides`、5区画）。
4. 黒い輪郭：手は銃の手前にあるので、手に接する輪郭は手のもの（輪郭の太さ7画素まで）。それ以外の黒は近い区画の部位。
5. 銃の本体につながらず片方の手にだけ接する50画素未満の欠片は、その手へ（グローブの外側の輪郭の縁にあった暗灰色の4画素と22画素を左手へ移した）。

- 手と銃の間の黒い線は、すべて手前にある手のものとした。銃の側の輪郭は、この画像では手に隠れていて存在しない。
- 左の指先の上のくぼみ（x 1012〜1014、y 507〜509）の黒い4画素：左手の輪郭とした。

## 再現手順

```sh
# 1. 分離（既存の出力がある場合は --force が必要。基準画像は書き換えない）
python3 Tools/pixelart/split_layers.py Assets/Game/Art/Weapons/Rifle/Layers/Hip/rifle_hip_layers.definition.json --force --report docs/review/player-parts/rifle-hip/split_report.json
# 2. 検証（一致しない・マスクの条件を満たさない場合は終了コード1）
python3 Tools/pixelart/verify_layers.py Assets/Game/Art/Weapons/Rifle/Layers/Hip/rifle_hip_layers.definition.json --report docs/review/player-parts/rifle-hip/verify_report.json --diff recomposition_diff.png
# 3. 色替えの確認画像（Assets の外へ）
python3 Tools/pixelart/recolor_preview.py Assets/Game/Art/Weapons/Rifle/Layers/Hip/rifle_hip_layers.definition.json out.png left:glove_body=215,0.40 right:glove_body=215,0.40
```

同じ定義で再実行すると、素材・マスクはファイル単位で同じ内容になる（ハッシュで確認済み）。手で決めた箇所（手の範囲・帯の区画・判定の数値）はすべて定義ファイルにある。

## 制約・未確認

- **固定の構え専用**：手を動かす、指を開く、握り方を変えるといった用途には使えない。手に隠れた銃の部分、銃に隠れた指は存在しない。
- **形の違うスキン**（指ぬきグローブ、袖のない腕、太い袖など）は、色替えではなく、この構えに合わせて描いた別の手・腕の素材が必要。その場合も、隠れていた銃の部分（今は手の下で描かれていない）を描き足した銃のレイヤーが必要になる。
- 掌・指の補強は判別できず、マスクは空。右手首の帯・右袖は画面外で見えない。
- 迷彩と地色の分け方は暫定の規則で、境界の数画素は人の目で確認が必要。
- ユーザー確認（2026-10-21）：接触部に大きな誤分類・欠落なし。色替え例は今回の配色で問題なし。袖の地色と迷彩のマスクは陰影との区別があいまいな部分があり、大きく異なる配色への対応は未確認（修正していない）。
