# 採用ライフルのADS：銃・左手と腕・右手と腕の分離（2026-10-21）

### ADS用に決めた値（腰だめの値は流用していない）

| 項目 | ADS | 理由 |
| --- | --- | --- |
| 左手の範囲 | x 0〜790、y 470〜887 | 左グローブ（x 600〜790）・帯・袖が画面左下にある |
| 右手の範囲 | x 1090〜1774、y 700〜887 | 右グローブが右下（x 1097〜1293）にある |
| 色の規則 | グローブ：色相18〜27°・彩度0.40以上・明度0.45以下／袖：色相38〜54°・彩度0.15〜0.36・明度0.45以下 | この画像のグローブ（色相21〜25°）・袖（42〜50°）を測定して決めた。銃の砂色（色相33〜36°）と重ならない |
| 輪郭の太さ | 10画素 | ADSは輪郭線が約10〜13画素（腰だめは約6〜8） |
| 色を保つ黒い線 | 最大チャンネル25未満 | ADSの線の黒の値を測定して決めた |
| 帯の区画 | 座標(627, 659)の灰色の区画 | 帯は銃の金属と同じ灰色で色では分けられない |
| 帯の影の面 | 多角形で指定（570画素を左手へ） | 帯の下側の暗い面（最大チャンネル30〜45）が帯の区画から離れていて、距離の規則では銃に入っていた |
| 袖の迷彩の判定 | 周囲30画素の明るさの上位15%より0.05以上暗い | ADSの袖は明暗の段が腰だめより少ない（明度0.20と0.35〜0.38の2つの山） |

ツールの変更：`split_layers.py` で、小さな欠片を手に戻す処理を、多角形での指定の後に実行する順番に変えた（指定で囲まれた黒い面の中に残った1画素・3画素の灰色が手へ戻るように）。腰だめの結果はこの変更の前後でファイル単位で同じ。

## 部位の分類（目視：`classification.png`・`contact_A〜E.png`・`layers_overview.png`）

| 箇所 | 確認結果 |
| --- | --- |
| A 左手の指先・ハンドガードの左側 | 指と周りの輪郭は左手、ハンドガードの砂色の部品は銃 |
| B 左グローブの下側と手首の帯 | 帯（明るい面・影の面）は左手。最初の結果では帯の影の面が銃に入っていたので、定義で修正した |
| C 袖・帯と機関部の左側面 | 袖・帯は左手、機関部の灰色の側面は銃 |
| D 右グローブと銃床の右側面 | グローブと輪郭は右手、銃床の砂色は銃 |
| E 照準器 | すべて銃（手の画素は入っていない） |

判断した箇所（暫定）：

- 手と銃の間の黒い線は、手前にある手のものとした（腰だめと同じ方針）。
- 帯の影の面と、左手の下の機関部の暗い面の境目は、黒い線と同じくらい暗く、画像からは境界の位置を断定できない。帯の形（明るい面と平行に右下へ細くなる）に沿って多角形を引いた。境界の数画素は確認が必要。

### 腰だめとADSの比較（`skin_compare_hip_ads.png`）

元の配色・グローブ変更・袖変更を、腰だめとADSで並べた。同じ設定でグローブは同じ青、袖は同じ紺の地色と迷彩になり、同じスキンに見える（Claude Codeの目視）。ADSは画面上の輪郭線が太く、袖の明暗の段が少ないため、迷彩の縞は腰だめより大きく見える（画像そのものの違い。修正していない）。

## 再現手順

```sh
D=Assets/Game/Art/Weapons/Rifle/Layers/ADS/rifle_ads_layers.definition.json
python3 Tools/pixelart/split_layers.py $D --force --report docs/review/player-parts/rifle-ads/split_report.json
python3 Tools/pixelart/verify_layers.py $D --report docs/review/player-parts/rifle-ads/verify_report.json
python3 Tools/pixelart/review_layers.py $D docs/review/player-parts/rifle-ads \
  "glove=left:glove_body=215,0.40;right:glove_body=215,0.40" \
  "sleeve=left:sleeve_base=210,0.10;left:sleeve_camo=220,0.25"
```

`review_layers.py`（今回追加）は、レイヤー一覧・再合成の比較・分類画像・接触部の拡大（定義の `review.areas`）・マスク図・色替え例をまとめて作る。`Assets` には出力しない。

## 制約

- 手に隠れた銃・銃に隠れた指は描かれていない。形の違うスキンは、この構えに合わせた手・腕の素材と、隠れた部分を描き足した銃のレイヤーが必要。
- 大きく異なる配色（明るい色・黒など）で迷彩と地色の分け方が十分かは未確認（腰だめと同じ）。
- 右手首の帯・右袖は画面外。掌の補強は判別できない。
