### 見た目の動きの調整（表示のみ）

従来の値（振り抜きで +60°回転・(−0.46, 0.12)へ移動・1.2倍）では、この画像の前腕が短くほぼ水平なため、**命中時間帯の中ごろから戻りの始めまで、袖の切り口（キャンバスの下端・右端）が画面内に入る**（iPhone 16 Pro・16:9・iPadのすべて。画像の実際の切り口の画素で計算）。大きさを変えても解消しない（画面の高さ1045／1300／1400画素で確認）。

調整：**振り抜きの回転 60° → 0°、振り抜きの位置 (−0.46, 0.12) → (−0.46, 0.04)**（配置ファイルの `motionOverrides`。この画像にだけ適用し、元の `MeleeView_ProtoKnife.asset` は変えない）。振りかぶりの −30° から振り抜きの 0° へ回転しながら左へ動くので、斬る動きは残る。左右の移動量・拡大・各段階の時間は変えていない。攻撃力・射程・攻撃間隔・命中時間帯・入力・通信上の判定は変更なし。

60°の回転を残したい場合は、前腕がより長く画面の右下へ続く画像が必要（下の「素材の不足」）。

## 4．素材の不足（60°の回転を残す場合）

前腕が短く、ほぼ水平に右へ伸びているため、従来の60°の回転では腕の切り口が画面に入る。60°の回転を残すなら、次の修正画像が必要：

```text
添付のナイフの画像（knife_candidate.png）と同じ画風・同じ手・同じナイフのまま、前腕と袖だけを長く描き直してください。
- 拳・ナイフの位置・大きさは変えない（拳の中心は (560, 730) のまま）。
- 前腕は手首から右下へ向かって、今より下向きに（水平から30〜40°下へ）、キャンバスの下端の外まで続くように長くする。
  キャンバスを右と下へ広げてよい（例：2200×1500）。左と上は広げない（座標がずれるため）。
- 袖の迷彩・明暗の段・輪郭線の太さは今と同じ。
- 背景は透明、半透明のピクセルは使わない。
```
