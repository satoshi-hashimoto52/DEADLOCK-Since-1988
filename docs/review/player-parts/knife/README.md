## 4．画像制作AI・外部制作への依頼文（案）

```text
一人称視点シューティングゲームで、右手でコンバットナイフを握った手元の2Dピクセルアートを1枚描いてください。

【画風】添付のライフルの腰だめ画像（rifle_hip_approved.png）と同じ画風・同じ手・同じ服にしてください。
- 1ドット＝4ピクセルの粗さ、太く暗い輪郭線、色数を絞った段階的な陰影。ぼかし・グラデーション・ノイズなし。
- 手は茶色の革グローブ（明暗の目安 #3A2417 #714426 #955B31）。手首に暗い灰色の帯（#262326 #413D3E #474344）。
- 袖はくすんだオリーブ色の迷彩（地色 #423C25 #72663E #776A41、迷彩 #2C2817 #464228 #4C472D）。
- ナイフは黒い柄と鋼の刃。刃に明るい縁と暗い面の段階的な陰影。

【構え】
- 右手の拳でナイフの柄を握る（指を柄に巻き込み、親指は柄の上）。刃先は左上を向く（順手）。
- 拳の右下に手首と帯、そこから前腕と袖が画面の右下へ続く。左手・銃・他の物は描かない。
- ライフルの手を変形して使わず、ナイフを握るための手として描く。

【キャンバスと位置】
- 2400×1500ピクセル、背景は透明（PNG、アルファ付き。半透明のピクセルは使わない）。座標は左上が原点。
- 拳の中心（柄を握っている位置）を (640, 600) に置く。
- 刃先は (402, 235) 付近（握りから左上へ）。
- 手首の帯は (770, 770) 付近。
- 前腕と袖は、帯からキャンバスの右下の角へ向かって、右端（y 1140〜1500）と下端（x 1880〜2400）まで途切れずに描く（キャンバスの端で切れてよい。そこは画面に出ない）。
- 刃・拳・手首・袖の手前側（キャンバスの左側から中央）は画面に大きく映るので、描き込みを優先する。

【含めないもの】背景、UI、ガイドの線・文字・色面、エフェクト（振りの残像など）。
```

## 5．届いた画像の取り込み・確認（参考）

1. 元画像を `Assets/Game/Art/Weapons/Knife/knife_approved.png` に置く（変更しない）。表示用画像を `python3 Tools/pixelart/make_opaque.py` で作る。
2. 握りの中心・刃先を実画像から読み取る（上の座標をそのまま使わない）。
3. ナイフの取り込みは今は `pixel_weapons.json` の暫定画像だけに対応している。採用画像を表示するには、ライフルの手元画像定義と同じような、ナイフ用の取り込み（ピボット＝握り、画面の高さに当たる画素数）を追加する作業が別途必要。
4. 部位の分離（色替え用）は `Tools/pixelart/split_layers.py` の手順で行う。**16画素未満の欠片を整理する規則**（`speckleMaxPixels: 16`）は、1ドット＝4画素（＝16画素）の画像を前提にしている。届いた画像のドットの大きさを測って、値を合わせてから使う。
