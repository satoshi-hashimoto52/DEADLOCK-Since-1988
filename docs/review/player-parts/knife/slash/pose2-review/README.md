### 袖の切り口

- **ガイドどおりの位置：見える**。命中時間帯の中ごろから（iPhone 0.134秒〜、16:9 0.142秒〜、iPad 0.156秒〜）表示の終わりまで、画像の右端の袖の切り口（縦の直線）が画面の右下に入る（`spec_*_2_pass.jpg`・`spec_*_3_after.jpg`、iPhoneとiPadで目視、3画面とも計算で確認）。下端の切り口は出ない。
- **配置だけで隠す場合**（`lowered_*`：握りを0.15単位下げて (0.20, −0.35)）：切り口は出ないが、刃が画面の下半分（中央より画面の高さの約25%下）を通り、「中央を横切る」仕様から外れる。→ 採用しない（比較用に記録）。
- 計算：ガイドどおりの位置で切り口を出さないには、袖を今の向き（右下、約29°）のまま**約260画素**延長する必要がある（余裕を含めて320画素を依頼）。
