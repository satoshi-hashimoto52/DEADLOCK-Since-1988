## 3. 修正が必要な点

| 点 | 種類 | 対応案 |
| --- | --- | --- |
| 4:3で刃先と拳が右端からはみ出す | **表示位置の調整で対応できる** | 画面が狭いときにポーズ1を左へ寄せる（腰だめの `hipRightEdgeFollowNarrow` と同じ考え方）。ゲームへ組み込むときに設定する。※下の注 |
| グローブが明るい（0.46、ほかは0.35〜0.37） | **色の補正で対応できる**（描き直しは不要） | グローブの範囲のマスクを作り、立ち絵のグローブと同じ方法（`recolor_mask_shift.py`）で明るさをそろえた派生画像を作る。元画像は保持する |
| 袖の向きが指定より寝ている（約47°） | 修正不要 | 切断面は全時点で画面外で、見た目も自然 |
| キャンバスが指定の1.14倍 | 修正不要 | 手とナイフの描かれた大きさは同じで、表示倍率を変えずに使える。握りの位置は実画像の値を使う |
| 描き直しが必要な点 | なし | — |

**※ 4:3の調整量について**：今回の計算では、2048×1536（4:3）で刃先側が最大64px（画像の画素）はみ出し、約0.046単位にあたった。約0.06単位はこれに少し余裕を足した**例**である。
- 単位はビューモデルのカメラ空間（z=1、画面の縦の半分＝tan25°≒0.466単位、横の半分＝0.466×画面比）。
- 握りの位置は時間割の設計値 (0.58, −0.16) に右端追従（`rightEdgeFollow` 0.5）を加えた位置で、表示倍率は1300px／画面の高さ。
- 画面比・端末・表示倍率・握りの位置が変われば必要な量も変わる。**ほかの解像度へそのまま当てはめる確定仕様ではない**。組み込むときに、各画面比で計算し直して決める。
