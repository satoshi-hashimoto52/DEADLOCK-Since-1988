# ナイフ ポーズ1（振りかぶり）・ポーズ3（振り抜き）：制作依頼資料（2026-10-21）

複数ポーズ案（`../README_multipose.md`）の残り2枚の制作依頼。ポーズ2（中央通過）は袖延長版で配置成立（`../pose2-review/extended/README.md`。継ぎ目は既知の見た目の課題として保持、画風・攻撃全体は未承認）。

## ポーズ2で分かったことと、今回の変更点

| ポーズ2で起きたこと | 今回の対応 |
| --- | --- |
| 届いた画像のキャンバスが指定より小さく（1339×1174）、袖が途中で切れた | ポーズごとに**袖を描く最低の長さ**と、袖を描き切れる大きさのキャンバスを指定する |
| 袖の向きがガイドと違った（約29°下向き。ガイドは約41°） | 推奨の向きから**±15°ずれても**切り口が画面に出ない長さを計算し、そのうち最も長いものを要求する |
| 延長部分で輪郭の太さが変わった（継ぎ目） | 袖は最初から1枚で描き切るよう依頼（後から足さない） |

キャンバス寸法と握りの位置は**ポーズごとに別**（ポーズ2の1680×1400・(610, 638)は使わない）。ドットの大きさは待機画像・ポーズ2と同じ（画面の高さ＝1300画素、輪郭線約9〜10画素）。

確認の方法（`Tools/pixelart/make_knife_pose13_brief.py`）：各ポーズを表示する時間割の1/60秒ごとの全時点を、iPhone 16 Pro・16:9・iPad 4:3の実際の位置・回転で計算（「どの角度でも切れない」ではなく、使う位置での確認）。数値：`pose13_requirements.json`。
