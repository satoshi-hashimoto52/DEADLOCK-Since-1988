## 2. 4:3での表示位置の調整（プレビューだけ）

調整前の4:3では、ポーズ1の刃が右端からはみ出した（最小の余白 −0.045）。ポーズ3は命中時間帯の後半で、刃の最大74%が左端の外へ出た（刃先も外。以前の記録の「約68%」は撮影の1時点での値。今回は命中時間帯の全サンプルのうち最も悪い時点の値）。

**調整の方法**：ポーズごとに動かすのではなく、軌道全体の横位置を中心 cx に向けて縮める（右端への追従の後で適用する）。

```text
x' = cx + (x − cx) × lerp(1, k, narrow)
narrow = InverseLerp(16:9, 4:3, 画面比)   … 16:9以上の画面では0（変わらない）、4:3で1
cx = 0.30、k = 0.67（単位：奥行1での画面座標。画面の高さの半分 = tan25°）
```

- 全時点に同じ変換をかけるので、軌道はなめらかなまま。ポーズの切り替わりの移動量は、もとの時間割の移動量の0.67倍に小さくなるだけで、新しい跳びは生じない。
- 待機位置の横のずれは −0.007（画面の高さの約0.8%）で、ほとんど動かない。
- 値は条件を満たす候補を探して選んだ一例で、仕様ではない（`layout_report.json`）。条件は次のとおり。
  - 袖の切り口が全時点で画面外。
  - ポーズ1の右端に余白0.015以上。
  - ポーズ3の命中時間帯に、拳と刃先が画面内。
  - ポーズ2の刃先が画面の中央を越える。

| 4:3（2048×1536） | 調整前 | 調整後 |
| --- | --- | --- |
| 握りの横位置：待機／ポーズ1／ポーズ2／ポーズ3 | 0.321／0.476／0.096／−0.484 | 0.314／0.418／0.164／−0.225 |
| ポーズ1の右端の余白 | −0.045（はみ出す） | +0.020 |
| ポーズ3の命中時間帯（攻撃中の後40%）に画面内にある刃の割合（最小） | 26% | **100%**（刃先も常に画面内） |
| ポーズ3の拳 | 画面内 | 画面内 |
| 袖の切り口 | 全時点で画面外（画面との最小の距離0.044） | 全時点で画面外（最小の距離0.044で変わらない） |

- 戻りの前半（ポーズ3が下へ沈む）では、刃・拳が画面の下へ出ていく。これは許容の範囲どおり。
- iPhone 16 Pro・16:9は narrow=0 なので、配置は調整前と同じ。
  - ポーズ1の右端の余白：iPhone 0.151、16:9 0.059。
  - ポーズ3の刃：命中時間帯は常に100%が画面内。
- 計算は、時間割の全サンプル（60fps）× 3画面比で行った（`layout_report.json`）。撮影でも確認した（`compare_4x3_layout_before_after.jpg`、`sequence_iPad_4x3.jpg`）。

**ゲームへの反映はしていない。** 一時的な撮影用テストの中だけで適用した。
