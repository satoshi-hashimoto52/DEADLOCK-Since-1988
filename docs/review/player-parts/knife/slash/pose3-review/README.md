## 2. 3ポーズの連続確認（Editorのプレビュー）

待機 → ポーズ1 v3 → ポーズ2（袖延長版）→ ポーズ3 → 待機を、既存の時間割（`Tools/pixelart/make_knife_pose_guide.py` の `TIMELINE`、振りかぶり0.12秒・命中時間帯0.12秒・戻り0.28秒）で表示した。
- 表示倍率は、どのポーズも画面の高さ1300px。
- 各ポーズの握りは、実画像から読み取った画素を設計の位置に置いた。ポーズ3の設計の位置は (−0.38, −0.30)。

| 確認 | 結果 |
| --- | --- |
| 握り | 待機・ポーズ1は手の甲、ポーズ2は親指側と指の背、ポーズ3は手の甲側。持ち替えたようには見えない |
| 刃の向き | 刃側は、待機 左下 → ポーズ1 左 → ポーズ2 下 → ポーズ3 下 と、一方向に回る流れで、逆戻りや裏返りはない |
| 大きさ | ナイフ・手の大きさに急な変化はない（ポーズ3は拳がやや遠近で縮むが、刃の長さは待機・ポーズ2と同程度） |
| 袖の切り口 | ポーズ3を表示する全時点（11サンプル）で、3画面比とも画面外。ただし**画面の端までの余白は最小61px**（画像の画素）で、ポーズ1（228px以上）より小さい。構図が下に描かれているため |
| 画面端の欠け（16:9・iPhone 16 Pro相当） | なし。16:9では、刃先が左端の近く（左端−0.829に対し−0.783）まで来る |
| 画面端の欠け（**4:3**） | ポーズ3の刃の**約68%が画面の左端から外へ出る**。ポーズ3の終わりには拳も左端にかかる（`iPad_4x3_07_pose3_start.jpg`・`iPad_4x3_08_pose3_end.jpg`）。設計の位置でも、4:3では刃先が左端の外に出る配置（狭い画面で右端へ寄せる設定 `rightEdgeFollow` の影響）で、画像だけの問題ではない。ポーズ1の右端のはみ出し（既知）と同じく、狭い画面での表示位置の調整が必要 |
| 戻り | ポーズ3が画面の下へ沈んで消え、待機が下から上がる（設計どおり） |

## 3. グローブの色差

暗部・中間・明部は、明るさの順に15%・50%・85%の画素の色。

| 画像 | 色相 | 彩度 | 明るさ | 暗部・中間・明部 | 待機との色差ΔE（暗・中・明） |
| --- | --- | --- | --- | --- | --- |
| 待機 | 22.3° | 0.52 | 0.37 | #6e3e24 #8f522e #9d5931 | — |
| ポーズ2 | 21.6° | 0.53 | 0.35 | #693a20 #894b2a #9d5731 | 1.8・3.0・1.3（ほぼ同じ） |
| ポーズ3 | 22.2° | **0.62** | 0.37 | #703b1b #9a5024 #a55628 | **5.1・8.8・7.1** |
| ポーズ1 v3 | 22.5° | 0.55 | **0.46** | #93502a #b76736 #bd6a37 | 15.0・15.1・12.1 |

ポーズ3は、明るさは待機と同じで、彩度が高く、中間の色がオレンジ寄り。差はポーズ1 v3より小さい。並べると分かる程度で、0.06秒前後の表示の間は目立ちにくい。そろえる場合は、ポーズ1と同じく、グローブの範囲だけ色を補正した派生画像で対応できる（描き直しは不要）。
