## 必要な素材：前腕の延長（`forearm_extension_guide.png`）

目標の動きで、腕の切り口が3つの画面比・全段階で画面に出ないための前腕（計算値）：

| 前腕の向き（画像で水平から下向き） | 手首から必要な長さ | 先端の位置（画像の左上が原点） |
| --- | --- | --- |
| 15°（今の画像に近い） | 約1600 px | (2295, 1204) |
| 30° | 約1400 px | (1962, 1490) |
| 45° | 約1300 px | (1669, 1709) |
| 60° | 約1100 px | (1300, 1743) |

前腕の延長だけで足りる理由：今の方式は画像全体を回すので、腕が画面の外まで続いていれば、どの角度に回しても切り口は見えない。指の形・握り方は今の画像のままでよく、振りの途中の形（コマ）は要らない。30〜45°下向きが、腕の長さが短くて済み自然。

### 制作依頼文（画像制作AI向け）

```text
添付のナイフの画像（knife_candidate.png、1586×992）と同じ画風・同じ手・同じナイフ・同じ袖のまま、
前腕と袖だけを長く描き直した画像を1枚作ってください。

- 拳・ナイフ・手首の帯の位置と大きさは変えない（拳の中心 (560, 730)、手首の帯 (750, 790)、刃先 (242, 206)）。
  キャンバスの左上は今と同じ位置にし、右と下にだけ広げる（例：2100×1800）。
- 前腕は手首から右下へ、水平から30〜45°下向きに伸ばす。手首から約1300〜1400ピクセル先まで、
  途切れずにキャンバスの端の外へ続くように描く（キャンバスの端で切れてよい）。
- 前腕は手前ほど少し太くなる（遠近）。袖のオリーブ色の迷彩・明暗の段・黒い輪郭線の太さ・ドットの粗さは今と同じ。
- 握り方・指・刃は描き直さない。
- 背景は透明、半透明のピクセルは使わない。ガイドの線や文字は描かない。
```
