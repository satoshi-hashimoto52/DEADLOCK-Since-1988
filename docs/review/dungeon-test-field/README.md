### 広さ（射撃場の約2.1倍）

同じ方法で測った（テスト `Layout_Closed_TwoFloors_WalkableAboutTwiceTheFiringRange`）。0.5mの格子で、立ったプレイヤーの当たり判定（半径0.35m・高さ1.8m）が入る床の面積を数えた。

| 場所 | 歩ける面積 |
| --- | --- |
| 遺跡：地上階 | 941㎡ |
| 遺跡：上階 | 724㎡ |
| 遺跡：階段2か所 | 39㎡ |
| **遺跡：合計** | **1,704㎡** |
| 射撃場（床は 16m×60m＝960㎡） | 814㎡ |
| **比** | **約2.09倍** |

射撃場の 814㎡ は、床から壁際の当たり判定の分と、障害物・トンネルを除いた値。

### 構造の決め方

- **階段**：当たり判定は30°のなめらかな坂にした。見た目は、その上に25段の段を描いている（足は段の面から0.1m以内）。しゃがみ・伏せ・スライディング中は、越えられる段差が0.05〜0.1mしかなく、本物の段では上れないため。
- **階段通路**：内側の壁は床から屋根まで続く。段の下の空間と、上階から階段通路への隙間は、端の壁で塞いでいる。
- **床・壁の分け方**：最大8mの単位に分けた。URPでは、1つの物に当たる点光源が4つまでなので、大きな1枚にすると近くの光が当たらないため。

### プレイ動画（`ruins_play_autopilot.mp4`、約44秒、960×540）

テスト用の自動操作で撮った（コミットしていない一時的なテスト）。進む経路は決めてあり、見えた敵には照準を合わせて撃つ。

1. 開始地点 → 南通路 → 大広間：地上階の3体を倒す。
2. 東の通路 → 東の階段を上る → 上階 → 回廊の東。
3. 追ってきた上階の2体を、回廊で倒す。

この自動操作では、プレイヤーは攻撃を受けなかった（敵より先に撃っているため）。敵の攻撃は、テスト⑤で確認した。

### 判明したこと

- **回廊の低い壁は、遮蔽物にもなる**：回廊の低い壁（1.3m）の内側からは、大広間の手前半分（回廊の真下に近い所）は見下ろしても撃てない。テストでは、大広間の奥（約15m先）の敵に当たることを確認した。低い壁の内側では、上下どちらからも隠れられる。
- **敵の方式は、変更しなくても上下階に対応していた**：
  - 移動：既存のNavMeshが、階段を通る経路を作る。
  - 攻撃：攻撃の前に頭から体への視線を確かめるので、床・回廊の低い壁・柱に遮られる。
  - そのため、敵の処理（`Zombie`）は変えていない。将来、低い壁のない段差や穴のある地図を作る場合は、上下の距離の制限が必要になる可能性がある（未対応）。
