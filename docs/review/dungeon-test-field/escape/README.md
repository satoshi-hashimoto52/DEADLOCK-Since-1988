## 1. ゲーム進行

- 既存の `TrainingSession`（結果の判定・入力の停止・シーンの読み直しによる再挑戦）をそのまま使い、遺跡では脱出地点（`ExtractionPoint`）を加えた。
  - 脱出地点がある場合、敵の全滅では終わらない（クリアにしない）。
  - 脱出地点がないトレーニングは、今までどおり全滅でクリア・死亡で失敗。
- 脱出地点：2階の北の通路、ギャラリーの北の扉のすぐ外（`(0, 5, 15.15)`）。
  - 開始地点（1階・南西）からは、階段の通路を上って北へ回る必要がある（NavMeshの道のりで30 m超、別の階。テストで確認）。
- 地点の範囲（暫定値）：中心から水平1.8 m以内、高さの差1 m以内。真下の1階は範囲に入らない。
- 地点に立つと「脱出する」ボタンが出る（PCではFキーでも可）。押すと生還。
  - 結果は、そのフレームの最後にまとめて決める。同じフレームに死亡も起きた場合は、**死亡を優先**する。
- 結果が決まった後：
  - 入力を止める（移動・射撃・近接攻撃なし）。経過時間も止まる。
  - ゾンビを止める（攻撃が当たらない）。
  - フロアマップの検知を止める（敵の印・足音の表示を残さない）。

## 2. 表示

- フィールド：緑の床の板と、ひざの高さの細い柱4本、緑の明かり。当たり判定はない（射撃・視線・足音は今までどおり通る）。
  - 柱は最初は2.4 mにしたが、地点の上に立つと画面の左右をふさいだため、0.9 mに下げた。
- ミニマップ：緑の扉の形。
  - 範囲内で同じ階：その位置。
  - 範囲外：枠の端（方位の「N」や敵の矢印より少し内側）。
  - 別の階：横に上・下の山形（▲／▼）。真上・真下のときは、自分の矢印の左の枠に出す（敵の枠は右）。
- 状態の行：「遺跡（試作）　脱出地点へ　討伐 n　m:ss」。
- 結果：「生還」または「死亡」、「経過時間 m:ss」、「討伐数 n」。ボタンは「再挑戦」と「メニュー」。
  - メニューを開いている間は結果の画面を下げ、閉じると戻す。
- 「脱出する」ボタン（340×92、置きたい位置はSafe Areaの横中央・下から30%）：
  - 次と重ならない一番近い位置に置く（ミニマップと同じ計算、8単位あける）。HUDの文字（一番長い表示で測る）、HPバー、メニューボタン、操作ボタン、ミニマップ、照準の周り。
  - 求め直すのは、画面の大きさ・操作レイアウト・ミニマップの位置が変わったときだけ。
  - 空きがない場合はボタンを縮めず、HUDも隠さない。置きたい位置に出し、ログに警告を出す。今回の3画面では空きが見つかった。

## 3. 別の階の敵：位置の印は出さず、足音だけ

- 上下の別の階にいて**見えていない敵**は、距離に関係なく、真上・真下でも、ミニマップに位置の印を出さない。
  - これまでの「別の階で聞こえた敵」の印（上下の三角、端の矢印と三角、自分の矢印の横の枠）は、聞こえた敵には使わない。
  - 階段や吹き抜け越しに**見えている**敵は、今までの見えた敵の表示のまま（変更なし）。
  - 同じ階の敵の表示は変更なし。
- 別の階の足音は、足音の表示（琥珀色の音の波と上下の山形）として一時的に出す。
  - 実際に足を踏み出したときだけ出る。止まっている敵は出ない。
  - 向きは8方向に丸める。真上・真下（水平2.5 m未満）は向きなしで、階表示の下の暗い板の上に出す。
  - 枠の端に出すので、距離は出ない。足音が出た時点の向きのままで、敵の今の位置を追わない。
  - 同じ向き・同じ上下の足音は1つにまとめる（敵の数も伝えない）。
- 別の階かどうかは、ミニマップと同じ求め方で決める（自分の足の高さ、階段での切り替えの遊び0.75 m）。
  - 同じ階で聞こえた印があるときに自分が別の階へ移ると、その最初のフレームから印を出さない。
  - 足音を出した敵が別の階へ移った場合も、前の階の印を消す。
- 値：
  - 足音の聞こえる距離と表示時間は、既存の設定をそのまま使う：15 m、壁・床1枚ごとに半分（床越しは7.5 m）、表示2秒。
  - 新しい暫定値：真上・真下とみなす水平距離2.5 m（`EnemyDetector.overheadRadius`、調整可）。8方向（45度刻み）。

- テスト用の銃の選択は、再挑戦でも残る（既存の仕組み）。
- 操作設定とミニマップの設定（保存値）は残る。
