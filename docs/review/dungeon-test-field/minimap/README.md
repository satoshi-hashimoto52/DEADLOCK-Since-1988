# 遺跡テストフィールド：フロアマップ（ミニマップ）の試作（2026-10-22、Issue #7）

遺跡テストフィールドで動く、開発用の試作。完成版のダンジョンや協力モードの機能ではない。

## 1. 表示

- 画面の左上、Safe Areaの内側に置いた。大きさは 188×188（基準の高さ1080のキャンバス単位）、角から14離した。
  - ノッチ、上中央のメニューボタンと状態の行、右上の弾数と姿勢、下中央のHP、初期配置の操作ボタンと移動の操作開始領域と重ならない。iPhone 16 Pro・16:9・4:3で、自動テストと画像で確かめた。
  - 表示だけで、タッチは受けない（下の操作にそのまま届く）。
  - Editor／PCでだけ出る操作説明の文字は、マップの右へ移す。
- 自分を中心にした「進行方向が上」の表示。マップが自分の向きに合わせて回る。小さな「N」が北の方向を示す。
- 表示する範囲は差し渡し22 m。自分の矢印は常に中央で上を向く。
- 表示するのは、いる階の床、壁、階段（段の線）、吹き抜け（斜線）。
  - 吹き抜けは、2階から見て下に床がない所。歩ける床とは色と斜線で区別する。
  - 階段は、つながる1階と2階の両方の図に出す。
- 階の表示は自動で切り替わる。床の高さの中間（2.5 m）から0.75 m越えたときだけ切り替えるので、階段の途中では往復しない。
  - 上りは足の高さ3.25 m、下りは1.75 mで切り替わる。
  - 階段を1回歩くと、切り替わるのは1回だけ。自動テストで確かめた。

## 2. マップの作り方（手描きの画像なし）

- 遺跡を作るエディターの処理（`RuinsSceneBuilder`）が、建物を作った直後にその当たり判定からマップを作る（`FloorMapBaker`）。結果は `Assets/Game/Generated/RuinsFloorMap.asset`。
  - 0.25 m四方のマス目で、各マスを物理の問い合わせで判定する。
  - 斜面（傾き0.5〜0.97）の上なら階段とする。
  - 体の高さ（床から0.5〜1.9 m）に物があれば壁とする。壁、柱、手すり壁、遮蔽物が該当する。
  - 床の高さの0.6 m下までに水平な面があれば床とする。
  - 何もなければ、2階では吹き抜け、1階では外とする。
- 通路を変えて遺跡を作り直すと、マップも作り直される。描き直しは要らない。
- 表示は、マップのデータから階ごとに作った小さな画像を回して動かすだけ。マップ用のカメラは追加していない。

## 3. 敵の表示（本作の試作仕様）

COD Mobile のように戦況を読み取れる使い勝手を参考にした。ただし検知のルールは本作の試作仕様で、COD Mobile のルールを再現したものではない。

特殊なパーク・スキルがない通常の状態では、次のときだけ敵を表示する。

1. **視認**：自分の画面の中に入っていて、目から敵の足・胴・頭のどれかまで、壁や床に遮られずに線が通る敵。距離だけでは判定しない。
2. **足音**：聞こえる範囲で足音を出した敵。
   - 足音の仕組みはまだないため、ゾンビの歩きのコマが切り替わる瞬間を1歩とした。歩く速さ0.3 m/s未満、攻撃中、死亡中は足音を出さない。止まっている敵は検知しない。
   - 足音の位置から自分の耳までの間にある壁や床1枚ごとに、聞こえる距離を半分にする。

- 表示する位置は、検知した時点の位置。検知が切れたあとは、隠れた敵の今の位置を追わない。見えている間と歩いて聞こえている間は、検知のたびに位置を更新する。
- 印の形：
  - 視認：塗りつぶした赤の丸。
  - 足音：黄色の輪。
  - 別の階の敵：上向き・下向きの三角に変える（塗りつぶし＝視認、中抜き＝足音）。いる階の敵と見間違えないように、丸や輪は使わない。
- 検知してから短い時間で消える（最後の4割の時間で薄くなる）。
- 死亡した敵の印は、その場で消す。再挑戦するとシーンを読み込み直すので、前の回の印は残らない。
- 今回追加していないもの：味方との情報共有、発砲による検知、常時の索敵、マップ以外の画面表示。

### 採用した仮の値（`EnemyDetector`、インスペクターで変えられる）

| 項目 | 値 | 理由 |
| --- | --- | --- |
| 視認の距離 | 50 m | 建物（42×35 m）のどこでも届く。霧の終わり（80 m）より手前。実際の制限は画面の中かどうかと遮蔽物 |
| 視認の更新間隔 | 0.1秒 | 1秒に10回。1回あたり、敵1体につき線の判定は最大3本 |
| 視認の表示時間 | 1.5秒 | 見失ってから短く残す |
| 足音の届く距離 | 15 m | 通路の一区間ほど。壁1枚で7.5 m、2枚で3.75 m |
| 壁・床1枚ごとの減衰 | ×0.5 | 隣の部屋の足音は近ければ聞こえ、遠ければ聞こえない |
| 足音の表示時間 | 2.0秒 | 歩く間隔（約0.28秒）より十分長く、歩いている間は途切れない |
| 足音とみなす最低の速さ | 0.3 m/s | 押されただけ、その場で向きを変えただけの動きを除く |
| 階の切り替えのゆとり | 0.75 m | 階段の途中やジャンプで往復しない |

### 将来のパーク・スキルのつなぎ口（今回は中身なし）

- 自分の側（索敵の強化）：`IDetectionModifier` を `EnemyDetector.AddModifier` で登録すると、視認・足音の距離に倍率をかけられる。
- 敵の側（足音の抑制）：`MapEnemy.FootstepLoudness`（初期値1）。
- パーク・所持品・オンラインでの同期は実装していない。

## 4. 設定

- メニュー → 設定 → 操作設定に「ミニマップを表示（遺跡）」のON／OFFを追加した。初期値はON。
- この端末に保存する（PlayerPrefs、キー `deadlock.hud.minimap.visible`）。次の起動でも戻る。
- OFFにすると表示を隠すだけ。検知、ゾンビの動き、戦闘は変わらない。
- 操作レイアウト、透過率、ADS、スキンの保存値は変更しない。キーも別にした。
- 画面に収めるため、操作設定の上3行の間隔を150から130に詰めた。

## 5. 負荷を抑える作り

- 敵ごとの重い探索はしない。視認の判定は0.1秒ごとに、敵1体につき線3本まで。
- 足音は、その1歩のときに線を1本引くだけ。範囲外なら線は引かない。
- 追加のカメラはない。マップの画像は読み込み時に1回だけ作る（173×143の2枚）。
- 毎フレームの処理は、回転、位置、印の更新だけ。

## 7. 修正（2026-10-22、実機導入の前）

### 範囲外の敵と、真上・真下の敵

- **範囲外**：検知した敵が表示範囲の外にいる場合、マップの外周（中心から80単位）に「切れ込みのある矢じり」を留め、その方向を指す。
  - 方向は、記録してある「最後に検知した位置」から毎フレーム求める。検知が切れた敵の今の位置は使わない。
  - 塗りつぶしは視認、中抜きは足音。色の区別も同じ。
  - 別の階の敵は、矢じりの内側に小さな上向き・下向きの三角を添える。
  - 範囲内の印（丸・輪・三角）とは形が違う。矢じりは外周にしか出ないので、そこに敵がいると読まれにくい。
- **真上・真下**：別の階の敵の位置が自分の矢印に重なる場合（中心から16単位以内、約1.9 m）、自分の矢印の右脇の枠（四角の囲み）の中に上向き・下向きの三角を出す。2体以上なら下へ並べる。
  - 四角の囲みは「位置ではなく知らせ」を表す形で、マップ上の敵の位置とは読み分けられる。
- 変わらないもの：視認と足音の区別、表示期限（期限後に消える）、別の階の上下の表示、検知距離、マップの縮尺。
- 確認（自動テスト `Markers_BeyondTheRange_OnTheEdge_…`）：
  - 18 m先の視認は外周の上。
  - 隠れて別の場所へ動いた後も、最後に検知した位置の方向を指す。北を向くと右になる。
  - 表示期限の後に消える。
  - 真上の足音は矢印の脇の枠に出る（中心から30単位右）。真下も同じ。
  - 2階から1階の遠い敵は、外周の矢じりに下向きの三角が付く。
- 画像：`minimap_edge_and_above_below_zoom.png`（行は iPhone 16 Pro・16:9・4:3、列は 範囲外・真上・下の階の範囲外）、`hud_edge_above_below_*.jpg`（画面全体）。

### 自分で動かした操作ボタンを避ける

- 実機の保存値を控えたところ、武器切り替えのボタンが左上の角に置かれていた（ユーザーが操作レイアウトで動かしたもの）。そのままではマップがボタンの上に重なる。
- マップは初期配置では左上の角に置く。操作ボタンがそこにあるときは、上端に沿って右へずらし、最初に空いた位置に置く。
  - 避けるもの：操作ボタン（8単位あける）、メニューボタンとその余白、上中央の状態の行、右上の弾数・姿勢の表示。
  - 0.5秒ごとに確かめ直すので、レイアウトの編集にもついていく。
- 確認（EditModeの自動テスト）：実機と同じレイアウトで、3画面比ともボタンに重ならず、状態の行の左に収まる。初期配置では左上の角のまま。

## 8. 気づいた点（未対応）

- 移動の操作開始領域は、浮いて出るスティックの土台が、押した位置によってはマップに一時的にかかることがある。表示だけの重なりで、操作は妨げない。
- 真上・真下の枠は、自分の矢印の右脇に出る。その位置には実際の敵がいないことを、形（四角の囲み）で示している。
