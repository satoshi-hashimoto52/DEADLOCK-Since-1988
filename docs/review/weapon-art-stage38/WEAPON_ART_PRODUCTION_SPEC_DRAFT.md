# DEADLOCK: Since 1988 — 武器画像の制作仕様（画像制作チャット向け・案）

> 状態：**案（未承認）**（2026-11-02 作成）。
> この文書は、画像を作るための依頼仕様です。ゲームへの採用は、ユーザーの承認と AssetPipeline の検査を通ってから決まります。
> 武器の正式名称・レアリティ・性能値は、まだ決まっていません。画像に名前・型番・文字を入れないでください。

## 0. 依頼の範囲

| 順番 | 画像 | 枚数 | 規格の状態 |
|---|---|---|---|
| 第1弾 | 側面全体図（ショットガン・ハンドガン・LMG・EPIC SMG） | 4枚 | **確定**（機械検査あり）。すぐ制作できる |
| 第2弾 | 一人称・腰だめ（同じ4武器） | 4枚 | 案。ユーザーの承認待ち |

## 1. 共通の画風（確定：既存の採用ライフルが基準）

基準の画像は、採用済みのライフルの腰だめと ADS です（D-041・D-043）。

- **画風：** レトロ FPS 向けの 2D ピクセルアート。背景より細かく描き込み、金属・グローブ・袖の質感を、ドットの形と陰影で表します。
- **ドット：** 1ドットは約4画素の大きさです。既存の画像と同じ粗さにしてください。
- **輪郭：** 太い暗い輪郭（2〜3ドット）。
- **陰影：** 段階的な陰影で、材質ごとに4〜5段階。
- **禁止：** ぼかし・グラデーション・ノイズ・アンチエイリアス・光のにじみ・写真的な質感。
- **アルファ：** 完全に透明（0）か完全に不透明（255）にします。半透明の縁は作らないでください。
- **背景：** 透明にします。床・影・背景・文字・ロゴ・型番・透かしは入れないでください。
- **時代感：** 1980年代の軍用銃の雰囲気です。特定の実在する銃をそのまま写さないでください。
- **見やすさ：** 暗い背景でも明るい背景でも、形が読めるようにします。
- **プレイヤーの手：** 一人称の画像だけに描きます。
  - 茶色の革のグローブ（補強の当て布つき）
  - 暗い色の手首のバンド
  - オリーブ色の迷彩の袖

### 色替え（スキン）のための描き方

ゲームでは、あとから色替えをします。色替えに使う領域図は、こちらでツールを使って作ります。画像制作の対象ではありません。そのために、次を守ってください。

- **銃の本体：** 色を変える部分（外装・ストック・ハンドガードなど）は、1つの色の系統でまとめて塗ります。例えば、ライフルでは砂色の部品です。
- **色を変えない部分：** 暗い鋼・照準器・黒い弾倉と握りなど。色を変える部分とは、はっきり違う色にします。
- **境目：** 色を変える部分と変えない部分の境、銃とグローブの境、グローブと袖の境には、暗い輪郭を入れます。

## 2. 第1弾：側面全体図（`weapon_side`、確定の規格）

### 2-1. 機械検査（1つでも外れると、受け付けられません）

| 項目 | 規格 |
|---|---|
| 形式 | PNG（壊れていないこと） |
| 解像度 | **1440×800 画素ちょうど** |
| 色形式 | RGBA、各チャンネル8ビット（PNG のカラータイプ6） |
| 背景 | 透明。完全に透明な画素があること |
| 外周 | 画像の外周1画素は、すべて完全に透明であること。銃がキャンバスの端に触れないこと |
| 内容 | 何かが描かれていること |

### 2-2. 目視の確認（ユーザーが承認の時に見る項目）

- 真横から見た図であること。斜めや上からの図にしないでください。
- **銃口が左、銃床（ストック）が右**を向いていること。
- 武器の全体が描かれていて、部品や輪郭の欠けがないこと。
- 余白と配置のバランスがよいこと。左右それぞれに100画素以上の透明な余白を取ってください。
- 既存の SMG の側面図と、画風がそろっていること。
- 文字・背景・地面・影がないこと。縦横比を変えていないこと。

### 2-3. 大きさの目安（案）

既存の SMG の側面図では、描かれている範囲が約 1224×511 画素です。

| 武器 | 描く範囲の幅の目安 | 説明 |
|---|---|---|
| ショットガン | 1150〜1240 | 長い銃。左右の余白は100画素以上 |
| LMG | 1150〜1240 | 長い銃。二脚は畳んだ状態 |
| EPIC SMG | 1100〜1240 | 既存の SMG と同じくらい |
| ハンドガン | 850〜1000 | 小さい銃。縦の範囲は約450〜550 |

- ゲームでは、表示する枠に合わせて縦横比を保ったまま縮小します。そのため、武器どうしの実際の大きさの違いは表示に出ません。上の幅は見栄えのための目安で、確定ではありません。

## 3. 第2弾：一人称の画像（案・承認待ち）

規格は、既存のライフルと SMG の画像に合わせた案です。

### 3-1. 腰だめ（hip）

| 項目 | 案 |
|---|---|
| 解像度 | **1672×941 画素** |
| 形式 | PNG、RGBA 8ビット、背景は透明、アルファは0か255 |
| 構図 | 右手で銃を持ち、画面の右下に置きます。腕と銃床は、画像の**下端**の外へ続くように切れていて構いません。右端の外へ続いても構いません |
| 空ける場所 | 画面の中央（照準）付近は透明にします。目安は、中心 (836, 470) から上下左右に約120画素の範囲です |
| 上端・左端 | 透明にします。何も触れないようにしてください |
| 描く範囲の目安 | 既存の画像では、左右は x≈580〜1670、上下は y≈380〜941 です |
| 銃口の位置の目安 | 既存の画像では (967〜972, 434〜443) 付近で、画像の中央のすぐ右です。銃身は画面の奥（中央の照準の方向）へ向けて描きます |
| 握りの位置の目安 | 既存の画像では (1260〜1265, 820〜880) 付近です |
| ハンドガン | 両手で持ちます（右手で握り、左手を添える）。銃が小さいので、手と腕の割合が大きくなります。画面の右下に寄せてください |

### 3-2. ADS（覗き込み）

| 項目 | 案 |
|---|---|
| 解像度 | **1774×887 画素** |
| 形式 | PNG、RGBA 8ビット、背景は透明、アルファは0か255 |
| 構図 | 両手で構え、照準器を覗き込んだ視点にします。袖は、画像の下端の外へ続きます |
| 照準の位置 | **フロントサイト（照星）の先端を、横は x=887（画像の中央）、縦は y≈386〜390 に置きます**。ゲームはこの点を画面の中央に合わせます |
| 照門 | 照門と照星が一直線に並ぶようにします。照門の切り欠きの中に、照星の先端が見えるようにしてください |
| 余白 | 上端・左右の端には触れないようにします。下端だけが外へ続きます。反動とリロードで画像が動くので、左右と上に余白を取ってください |
| 描く範囲の目安 | 既存の画像では、左右は x≈270〜1370、上下は y≈365〜887 です |
| ショットガン | 照星はビーズ（丸い点）でも構いません。先端の位置は上と同じです |
| ハンドガン | 両手で前に突き出して構えます。照門と照星を一直線に並べます |
| 代わりの方法 | 2400×1200 で描いて、0.739倍に縮小して納品する方法もあります（ライフルはこの方法でした）。縮小した後も、アルファは0か255にしてください |

### 3-3. 腰だめと ADS をそろえること

- 同じ銃・同じグローブ・同じ袖に見えるようにします。
- ADS の輪郭が腰だめより太く見えるのは、既知の差として許容されています。

## 4. 武器ごとのデザイン（案・ユーザーが修正してよい）

| 武器（社内の仮の呼び名） | 形 | 色 |
|---|---|---|
| ショットガン | 1980年代のポンプ式。管状の弾倉と、銃身の上のビーズの照星。スコープは付けない | 暗い鋼の銃身、木か黒い合成樹脂のフォアエンドと銃床 |
| ハンドガン（サブ銃） | 角ばった9mmの自動拳銃。アイアンサイト | 暗い鋼のスライド、黒い握り |
| LMG | 軽機関銃。二脚は畳んだ状態。大きな箱形の弾倉（またはドラム）、太い銃身と放熱の穴、持ち運び用の取っ手 | 砂色の部品と暗い鋼（ライフルと同じ系統） |
| EPIC SMG | 既存の SMG の系統（箱形・針金の銃床）の試作品。むき出しのネジ、溶接の跡、配線、手描きの白いマーク（文字にしない） | 黒と濃い灰色。機関部に琥珀色の小さな表示灯、照門の横に緑の小さな点 |

- **EPIC SMG の特別さ：** 特別な感じは、絵の中に描き込んで表します。発光のための別の画像は作りません。
- **EPIC SMG で避けること：** ネオン、光る線、ホログラム、未来的な曲面、SF 風の形。
- **ハンドガン：** 装備ではサブ銃の枠（Slot 2）専用です。
- **既存の SMG との違い：** 通常の SMG（既存）と EPIC SMG は、別の武器です。ひと目で区別できるようにしてください。

## 5. 納品のしかた

- **ファイル名：** 次の表のファイル名で納品してください（受け取りの時の名前です）。
- **受け取りの場所：** AssetPipeline の `_inbox/<素材ID>/` に置きます。素材ID は、正式に決まるまで案です。

| 素材ID（案） | 画像 | ファイル名（案） |
|---|---|---|
| `weapon.shotgun.side` | ショットガンの側面図 | `shotgun_side_design.png` |
| `weapon.handgun.side` | ハンドガンの側面図 | `handgun_side_design.png` |
| `weapon.lmg.side` | LMG の側面図 | `lmg_side_design.png` |
| `weapon.epic_smg.side` | EPIC SMG の側面図 | `epic_smg_side_design.png` |
| `weapon.<武器>.hip` | 腰だめ（第2弾） | `<武器>_hip.png` |
| `weapon.<武器>.ads` | ADS（第2弾） | `<武器>_ads.png` |

- **半透明の画像になった場合：** 原本はそのまま納品してください。アルファを2値にした派生画像（`*_opaque.png`）は、こちらで作ります。
- **確認用の画像：** 明るい背景と暗い背景に重ねた確認用の画像を、別のファイルで付けてください。ゲーム用の画像とは別にします。
