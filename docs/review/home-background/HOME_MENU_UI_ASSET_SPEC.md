## 0. 共通ルール

### 0.1 単位

- **デザイン px**：正本画像（1672×941）上の px。Unity のホーム UI のキャンバスは高さ941単位なので、1デザイン px = 1キャンバス単位。
- 端末での大きさ（倍率1.0のとき）：
  - iPhone 16 Pro（2622×1206）：1デザイン px ＝ 1.28 画面 px
  - iPad 4:3（2048×1536）：初期倍率0.75で、1デザイン px ＝ 約1.22 画面 px
- 自由配置で倍率は 0.5〜1.4倍（ロゴ・ポイント・Crate は1.6倍、設定は1.8倍まで）変えられる。iPhone では最大で、1デザイン px ＝ 約2.3 画面 px になる。

### 0.2 解像度とドット

- ドット絵の1ドット（**アートpx**）は、原則 **2デザイン px**。パネルの枠だけは細い線が必要なので、1アートpx ＝ 1デザイン px とする（§1）。
- 納品する PNG は、すべて**2デザイン px あたり4 PNG px ＝ 1デザイン px あたり2 PNG px**（以下「2倍密度」）。
  - アイコン：アートpx を最近傍法でちょうど4倍に拡大したもの。
  - パネル：アートpx を最近傍法で2倍に拡大したもの。
- 拡大は、最近傍法の整数倍だけ。ぼかし・アンチエイリアス・補間で作った中間色は入れない。

### 0.3 透過と形式

- PNG、RGBA、sRGB。背景は実際の透過（市松模様や黒で塗りつぶさない）。
- アルファは原則 0／255。半透明はパネルの中央の面（§1）だけ。
- 周りの余白は、各素材に指定したキャンバスの大きさのまま。図柄だけを切り詰めない。連番ではない。

### 0.5 Unity での取り込み（全素材共通）

- Texture Type：Sprite (2D and UI)、Sprite Mode：Single、Pixels Per Unit：100、Mesh Type：Full Rect。
- **Filter：Bilinear**（2倍密度の素材を約0.6〜1.2倍で表示するため、Point だとドットの太さが不ぞろいになる）。
- **Mipmap：なし**、Compression：None、Wrap：Clamp。
- Max Size：2048（ロゴ以外は1024で足りる）。
- Image の Preserve Aspect：オン（パネル以外）。
- 縦横比を変える拡大は、パネルの 9-slice 以外では行わない。
- 状態（通常・押下・選択・無効）は、同じ素材を Unity の色で変える（§1.4）。状態ごとの別の PNG は作らない（仕様書 §5）。

### 1.3 Unity での使い方

- Sprite Editor で Border を L=40／R=40／T=40／B=40 に設定する。
- Image の Type：Sliced、Fill Center：オン。
- Pixels Per Unit Multiplier：**2**。2倍密度の素材の枠が20デザイン px の太さで表示される。
- 9-slice：**必要**。寸法の違うすべてのパネルを1枚で作るため。最小の表示寸法は 40×40 デザイン px。
- Pivot：中央（0.5, 0.5）。ただし Sliced の Image では Pivot は表示に影響しない。

### 4.3 受け取りの手順

AssetPipeline README のとおり。

1. ID を追加したあと、画像を `AssetPipeline/_inbox/<素材ID>/` に保存する（例：`_inbox/home.ui.menu.icon.survival/home_icon_survival.png`）。
2. `./assetpipe scan`（または `watch`）で受け付ける。RGBA であること・透明な画素があること・半透明の有無を自動で検査する。
3. 目視で確認する：寸法（§4.1）、2倍密度、ドットの大きさ・輪郭・色数（§0.4・§2.4）、正本画像との見た目の一致。
4. ユーザーの承認のあと、`approve` → `register` で登録する。
