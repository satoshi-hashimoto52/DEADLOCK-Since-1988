## 判断項目と推奨

| 判断項目 | 推奨 | 理由 |
| --- | --- | --- |
| 外装の配色 | **現状で採用できる** | 色相・彩度が一致し、装備画面と一人称で同じタン色に見える |
| アイアンサイト（前後） | **現状で採用できる** | 違いは視点だけで、形と位置は一致する |
| 機関部と部品の配置 | **現状で採用できる** | 通気溝・弾倉受けの溝・赤い表示・つまみ・弾倉の位置関係が一致する |
| 銃口部品 | **現状で採用できる** | 黒い段付きの筒という形は同じ。一人称では小さく、細部の差は目立たない。将来サプレッサーへ交換する部品でもある |
| ハンドガードの穴 | **現状で採用できる**（気になる場合のみ、採用前の修正を検討） | タンのハンドガードに暗い穴、上面にタンのレールという構成は同じで、同じ銃に見える。穴の数と並びの差は、装備画面と一人称を並べて見比べない限り目立ちにくい。厳密にそろえるなら全体図の描き直しが必要で、費用に対して効果が小さい |
| 補完した部分（引き金・グリップ・下面のレール・銃床の後半） | **現状で採用できる** | 一人称で見えている部分と矛盾しない |
| 用心金の色替え | **現状で採用できる**（今の「外装と一緒に色が変わる」ままとする） | 用心金はタン色の外装として描かれている。色替えから外すと、武器スキンで緑にしたときに用心金だけタン色で残り、塗り残しのように見える。どちらにするかは、画像を変えずに領域マップだけで変えられる |
| サプレッサー用の余白（今の単体表示） | **現状で採用できる** | 今の装備画面は銃全体を1枚で表示しており、銃口の左の余白（98px）で欠けはない |
| サプレッサー用の余白（将来の拡張） | **将来の部品分離・拡張時に対応できる** | 下の「余白の拡張」のとおり、縮小せずに透明の余白を足せば対応できる |

## 余白の拡張（将来、今回は加工していない）

- **方法**：画像を縮小・移動せずに、キャンバスの左へ透明の画素を足す（例：260px → 2120×846）。絵の画素はそのまま残る。
- **基準点への影響**：足した幅だけ、すべての横の座標がずれる（銃口の先端 x=98 → 98+足した幅。銃身の中心線 y≒358 は変わらない）。領域マップ・マスク・後で作る部品レイヤーも、同じ幅で一緒に余白を足す。
- **必要な幅の目安**：制作資料では、サプレッサーの長さを指定の縮尺で約260pxとした。この全体図は指定より約1.32倍大きく描かれているので、同じ割合なら約345px。今の98pxに加えて、250〜300px程度が要る。サプレッサーの絵は、この全体図と同じドットの粗さで描く必要がある。
- **装備画面への影響**：今のプレビューは、キャンバス全体を枠に収めて表示する。キャンバスが広がると、銃が小さく、右寄りに表示される（例：枠の幅776pxに対して表示倍率0.417→0.368）。大きさを保つには、キャンバス全体ではなく銃の範囲を基準に配置する表示処理が必要（部品の交換・追加を実装するときに対応）。
- **照準器の余白**：照準器の上端（y=187）より上に約187pxある。スコープの大きさ次第では、上にも同じ方法で余白を足す。
