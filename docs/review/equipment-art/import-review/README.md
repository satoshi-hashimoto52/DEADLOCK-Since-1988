# 装備画面用素材：検査・取り込み・装備画面の最小表示（2026-10-21）

届いた2枚（ライフル横向き全体図、標準プレイヤー正面立ち絵）の検査、Unityへの取り込み、色替え領域、装備画面での表示とスキン連携の記録。

2枚とも**制作候補**で、仕様との適合や正式採用はまだ確認されていない。色違い（`test_green`・`test_navy`）は検証用の仮配色。確認は**Editorでの確認まで**で、iPhone実機ではまだ確認していない。

## 3. 色替え領域

ツール `Tools/pixelart/make_image_regions.py` を新しく作った。1枚の画像のまま、部品分離をせずに領域マップを作る。
- 黒い輪郭線で区切られた区画ごとに、「指定範囲の中にあるか」と「色の規則に合うか」で判定する。色だけでは選ばない。
- 線の黒は入れない。
- 袖の地色と迷彩は、既存ツール（`split_layers.py`）と同じ局所コントラストの方式で分ける。
- 重なり・線の黒・透明画素・範囲外への混入を検査する。2枚とも0件だった。

## 4. 装備画面の最小表示

| 項目 | 内容 |
| --- | --- |
| 開き方 | メニュー（画面上部中央のボタン、PCはTab）→ 設定 →「**装備・スキン（テスト用）**」 |
| 画面 | 既存の「スキン（テスト用）」画面を作り替えた（同じ用途の画面と保存処理を重複させない）。左にプレイヤー（正面）、右上にライフル（横）、右下に武器と手・腕の選択、「すべて標準に戻す」、「戻る」。プレイヤーにライフルを持たせる合成はしていない |
| 配置 | 1392×1000（キャンバス基準）の不透明なウィンドウを Safe Area の内側の中央に置く。画像は縦横比を保ち、全体が枠内に収まる |
| 連動 | スキンID・選択・保存は既存の `SkinSelection`／`SkinCatalog` を共有する。ライフル外装を変えると、全体図と一人称の腰だめ・ADSが変わる。手・腕を変えると、立ち絵のグローブ・袖と、一人称の腰だめ・ADS・ナイフが変わる。ボタン以外で選択が変わった場合も、表示と文言が追従する |
| UIの色替え | 一人称用の `Deadlock/Skinned Sprite` は `SpriteRenderer` 用のため、UIには流用していない。新しい `Deadlock/Skinned UI`（UnityのUI-Defaultと同じステンシル・矩形クリップ・アルファクリップ・乗算済みアルファ・頂点色の扱い）を追加した。色計算は `SkinColour.hlsl` を2つのシェーダーで共有する（一人称のシェーダーもこの共通ファイルを使うよう変更。計算内容は同じ） |
| 描画用リソース | uGUIは描画単位のプロパティ（MaterialPropertyBlock）を使えない。そのため、画像ごとにマテリアルを**1つだけ**作り、色の変更時は値だけ更新する。画像を破棄するときにマテリアルも破棄する（`SkinnedImage`） |
| 変更していないもの | 武器性能・通信・操作配置・操作ボタンの透過率・ADS設定。対戦中の他プレイヤーの表示は対象外 |

キャプチャの条件（撮影のための一時的な変更で、ゲームは変えていない）：
- オーバーレイ表示のUIはレンダーテクスチャに描かれないため、撮影時だけUIをワールド用のカメラで描いた。
- 装備画面の撮影中は一人称の武器を消している。実際の画面では、武器は暗いパネルの奥にうっすら見える。
- Safe Areaは、iPhone 16 Proの横向きの値を手で再現したもの。
