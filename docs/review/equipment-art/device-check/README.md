# 装備画面：iPhone 16 Pro 実機確認（2026-10-21）

装備画面（メニュー → 設定 →「装備・スキン（テスト用）」）と、一人称表示とのスキン連動を、実機で確認した記録。

画像2枚（ライフル全体図・プレイヤー立ち絵）は**制作候補のまま**で、正式採用ではない。色違い（`test_green`・`test_navy`）は検証用の仮配色。

## 1. 撮影用の構成と通常実行時の構成

| 項目 | 結果 |
| --- | --- |
| 前回のEditorの画像での「UIをワールド用カメラで描画」「一人称の武器を非表示」 | **撮影専用**。削除済みの一時テスト（`TmpCapture`、コミットなし）の中だけで行った変更 |
| 通常の実行時 | UIはオーバーレイ表示のまま（シーンの `m_RenderMode: 0`）。撮影用の設定や一時オブジェクトには依存していない |
| 実機での見え方 | ウィンドウ内はEditorの画像と同じ構成。ウィンドウの外側に、一人称の武器が暗いパネル越しに見える（武器は消していない） |
| 閉じたとき | メニューを閉じると入力のブロックが解除され、武器と操作が戻る。PlayMode `EquipmentScreen_OpenCloseEvents_InputBlockedOnlyWhileOpen_WeaponBack` と実機で確認。カメラは装備画面で変更していない |
| 繰り返し・シーン遷移 | 開閉とシーン遷移を繰り返しても状態は残らない（PlayModeと実機のログ） |
| 対戦中 | 装備画面はメニューの中の1画面。メニューの入力ブロックとオンラインで止めない動作は既存のまま（変更なし） |
| UI用シェーダー | `Deadlock/Skinned UI` はスキンカタログ → シーンのメニューから参照され、iOSビルドに含まれる。Metal向けに頂点・フラグメントとも4バリアントをコンパイル（`Logs/ios-export.log`）。ビルドの容量の記録にも含まれる（シェーダー9.2 KB、マテリアル0.3 KB）。実機での表示異常なし |

## 5. 負荷

計測は、開発ビルドの `EquipmentScreenDiagnostics` と `FrameRateMonitor`（10秒ごと）による。
- 開閉・色替えのイベントごとに、直後の1秒間で最も重いフレームを記録した。3回の起動で合計64回。
- 自動スクリーンショットの保存イベント（`capture … at 時刻`）は、各イベントの1.2秒後に記録される。

**開閉・色替えの直後1秒間（除外前、全64回）**

| 区分 | 回数 | 最大 |
| --- | --- | --- |
| 初回表示 | 3 | 131.8 ms |
| 2回目以降の表示 | 10 | 21.4 ms |
| 閉じる | 13 | 134.9 ms |
| 色替え | 38 | 136.0 ms |

**保存イベントの時刻が、その1秒間に含まれていた12回を除いた結果（52回）**

| 区分 | 回数 | 最大 |
| --- | --- | --- |
| 初回表示 | 3 | 131.8 ms（インストール直後の1回目の起動）。再起動後の2回は17.7・18.0 ms |
| 2回目以降の表示 | 10 | 21.4 ms |
| 閉じる | 11 | 18.4 ms |
| 色替え | 28 | 19.6 ms |

保存イベントと重なった12回について：
- 値は117.4〜136.0 msで、12回すべてが100 msを超えた。重ならなかった52回で100 msを超えたのは、初回表示の131.8 msの1回だけ。
- 確認できたのは、**保存イベントの記録時刻が計測の1秒間に含まれていた（時間帯が一致した）こと**だけ。重いフレームと保存処理が同じフレームかは記録しておらず、**保存処理が原因とは断定できない**。

**初回表示の131.8 ms**：インストール直後の1回目の起動で、初めて装備画面を開いた直後の1秒間に1回発生した。保存イベントとは重なっていない。**原因は未特定**。

**10秒ごとの記録（`FrameRateMonitor`）**

| 区分 | 観測 |
| --- | --- |
| 起動直後の最初の10秒区間 | 3回の起動とも、最も重いフレームが約2.1秒（2114・2104・2125 ms）。原因を裏付ける情報はない。1回目・2回目の起動では、この区間は**装備画面を開く前**だった（最初の開閉イベントは590.95秒・97.57秒）。3回目の起動では、同じ区間の中で装備画面を開いて（5.05秒）閉じている（7.61秒）。開いた直後・閉じた直後の各1秒間の最も重いフレームはどちらも18.0 msで、約2.1秒のフレームはその2つの1秒間には入っていない |
| 通常プレイ | 平均60 fps、10秒区間ごとの最も重いフレームの中央値は約17 ms |
| 約700 ms・768 msの区間 | 2回あった。どちらも、その区間の記録の直前に、アプリがいったん非アクティブになりまた戻った記録（`sceneWillResignActive`／`applicationWillResignActive` と `sceneDidBecomeActive`）があった。時間帯の一致で、原因とは断定しない |

- **プレイヤー**：グローブが明るいオレンジ寄りである点、肩パッチ・カーゴポケット・耳当て、手・腕以外の全身のデザイン。
