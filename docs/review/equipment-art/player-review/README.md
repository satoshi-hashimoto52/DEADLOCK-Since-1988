## 部位別の推奨

| 部位 | 推奨 | 理由 |
| --- | --- | --- |
| ヘルメット・ゴーグル・耳当て | 現状採用を推奨 | 砂色のヘルメットはライフル外装のタン色と同系で、武器と並べて配色がそろう。ゴーグル・耳当ては暗い色で輪郭がはっきりしている。推奨案（ヘルメット＋額のゴーグル）どおり。耳当ては推奨案になかった追加だが、軍装として自然で、形の読み取りを妨げない |
| 目元・ネックゲイター | 現状採用を推奨 | 目元は見え、口と鼻は暗い灰で覆われていて、推奨案どおり。ゲイターの灰は手首の帯と同系。個人の特徴を強く決めすぎていない。ただし、顔立ち（目・眉・肌の色）が標準キャラクターの顔として固まる点はユーザーの判断事項 |
| 迷彩の上着・ズボン | 現状採用を推奨 | 上着・袖・ズボンは同じ迷彩で、色もほぼ同じ（袖とズボンの色相43.3°・彩度0.34、明るさ0.35／0.33）。<br>一人称の袖（色相44〜47°、彩度0.24〜0.29、明るさの中央値0.24〜0.29）と比べると、明るさは一人称の明るい部分（明るいほうから10%の値で0.36〜0.38）と同程度で、正面から光が当たった1枚絵として自然な範囲。彩度はやや高い。<br>そろえる場合は、上着・袖・ズボンを一緒に変える必要がある（袖だけ変えると胴・ズボンと合わなくなる）。胴・ズボンの領域はまだないため、今は変えない方がよい |
| プレートキャリア・前面ポーチ・ベルト | 現状採用を推奨 | 暗いオリーブの胴体装備と暗い灰のベルトで、迷彩と区別できる。推奨案（弾倉ポーチ2つ）どおり。ポーチは飾りで、予備弾の装備効果を表すものではない（GAME_SPEC 9.2の「予備弾ポーチ枠」ではない） |
| 肩パッチ・カーゴポケット | 現状採用を推奨 | 推奨案になかった追加。パッチは無地で、文字・記章・ロゴがない。ポケットは輪郭線で区切られていて、迷彩を読みにくくしていない |
| 膝当て・ブーツ | 現状採用を推奨 | 推奨案どおり（暗い灰の膝当て、暗い茶の編み上げブーツ）。ブーツの茶はグローブより暗く灰寄りで、別のものとして見分けられる |

修正を推奨する部位はない。どの部位も推奨案から大きく外れておらず、一人称（グローブ・袖）、ライフル（タン色）と並べても同じ装備の人物に見える。

## 残る判断事項

- 上の各部位の採否（ユーザーの判断）。特に、標準キャラクターの顔立ちとして固めてよいか。
- 迷彩の彩度が一人称より少し高い点を許容するか（そろえる場合は、全身の部品分離か、胴・ズボンの領域作成が先に必要）。
