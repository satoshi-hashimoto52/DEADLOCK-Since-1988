# プレイヤー立ち絵：標準グローブの配色候補（2026-10-21）

立ち絵（`Assets/Game/Art/Player/Front/player_front_design.png`）のグローブは、一人称の素材より明るくオレンジ寄りだった。そこで、一人称のグローブに合わせた落ち着いた茶色の候補を1案作った。

**候補であり、正式採用ではない。** ゲームで使う画像・マスク・スキン定義は差し替えていない。元画像も変更していない（ハッシュは `107e0a51…` のまま）。

## 配色の基準

基準の色は、スクリーンショットではなく、採用済みの元画像から測った。グローブの範囲は、各画像の既存のグローブ用マスクを使った。

| 画像 | 色相（中央値） | 彩度（中央値） | 明るさ 中央値／明るい95% |
| --- | --- | --- | --- |
| 腰だめ `rifle_hip_approved.png`（採用済み） | 23.7° | 0.472 | 0.322／0.414 |
| ADS `rifle_ads_approved.png`（採用済み） | 22.8° | 0.498 | 0.371／0.402 |
| ナイフ `knife_candidate.png`（候補） | 22.3° | 0.515 | 0.367／0.408 |
| 立ち絵（現在版） | 26.4° | 0.532 | 0.412／0.457 |
| **立ち絵（候補版）** | **23.2°** | **0.485** | **0.369／0.408** |

- **基準にした画像**：採用済みの腰だめとADSの2枚。ナイフはまだ候補なので、参考にとどめた。
- **色相・彩度**：2枚を合わせた値（23.17°、0.483）を使った。
- **明るさ**：2枚の「明るい95%」の平均（0.408）を使った。
- **中央値を使わなかった理由**：腰だめは右手が大きく陰になっていて中央値が低い（0.322）。描かれた光の条件の差なので、明るい部分を合わせた。
- **候補の中央値（0.369）**：ADS・ナイフとほぼ同じ値になった。

## 作り方

ツールは `Tools/pixelart/recolor_mask_shift.py`（今回追加）。
- 既存のグローブ用マスク `Assets/Game/Art/Player/Front/Masks/player_front_glove_body.png` の中の画素だけを変える。
- 色相は −3.27°ずらす。彩度は0.907倍、明るさは0.893倍にする（HLS、8bitのsRGB値で計算）。
- 倍率はグローブ全体で1つなので、描かれた陰影の並び順と段階どうしの比は変わらない。
- 新しいイラストの生成や、形の描き直しはしていない。

## 変更範囲の確認

| 確認 | 結果 |
| --- | --- |
| 寸法・アルファ | 元画像と同じ（アルファが変わった画素は0） |
| マスクの外 | 変わった画素は0（手首の帯・袖・その他の部位は変更なし） |
| マスクの中 | 18,273画素すべて（線の黒はもともとマスクに入っていないので、輪郭は変わらない） |
| 陰影の順序 | 元の明るさの順に並べたとき、候補で順序が逆転した画素は0 |
| 色の数（マスク内） | 5,594 → 4,359。明るさを下げたため、ごく近い色どうしが8bitの丸めで同じ値になった |
| 目視 | 輪郭・指の形・手のひらの当て布・陰影の段階は、つぶれていない。暗い背景でも形が読める |

## 判断待ち

- 候補の採否（ユーザーの判断）。
- 採用する場合に、ゲームで使う画像へ反映する手順（元画像の差し替えか、派生画像の追加か）。
- グローブ以外の全身のデザインと、ライフルの判断点（`../device-check/README.md` の7章）。どちらも別件のまま。
