## マスク・領域マップの再利用

| 確認 | 結果 |
| --- | --- |
| 寸法・アルファ | 採用前と採用後の表示用画像は、同じ寸法でアルファが一致（違いは0画素）。違いはグローブのマスク内の18,273画素だけ |
| 既存の領域マップの再利用 | 画素の位置はそのまま使える。ただし、明るさを下げたため、グローブのごく暗い陰の**107画素**（元は最大チャンネル18〜20）が、線の黒の基準（18未満）を下回った |
| 対処 | 既存の領域マップから、その107画素だけを外した派生を作った（`Tools/pixelart/reuse_region_map.py`）。ほかは既存のまま：グローブ18,166画素、手首の帯3,121、袖の地色27,945、袖の迷彩42,321（帯・袖は既存と同じ画素数）。外した107画素は、どのスキンでも描かれた色（ほぼ黒）のまま |
| 定義から作り直した場合（参考） | 同じ定義で採用画像から作り直すと、暗い陰の画素の区切り方が変わり、グローブは18,112画素になる。既存の領域を基本にするため、作り直したマップは使っていない |
| 既存のマップとマスク | 元画像用として保持（変更なし） |

## 試作スキン（手・腕）の見え方の変化

試作スキン `test_navy` は、色相・彩度を置き換え、描かれた明るさを残す方式。そのため、グローブの明るさを下げた分だけ、紺のグローブもやや暗くなった（グローブの明るさの中央値 0.414→0.369、明るい部分 0.457→0.408）。
- 輪郭・指・当て布・陰影は保たれている。
- 結果として、一人称（腰だめ・ADS）の紺のグローブの明るさに近づいた。
- 不自然な差はないと判断し、一人称用の画像や共通のスキン定義は調整していない。
- 比較：`compare_skin_before_after_adoption.png`（採用前・採用後 × 標準・試作色。同じ計算式による画像のプレビュー）。
