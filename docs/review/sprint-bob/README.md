# ダッシュの上下動（2026-10-21）

ユーザーの指摘（iPhone 16 Pro）：ダッシュ時は体の上下動を強め、走っている感覚を出したい。

## 変更

| 項目 | 内容 |
| --- | --- |
| カメラ（新規 `CameraBob`、ワールドのカメラに付ける） | ダッシュ中だけ、足の運びに合わせて**下へ沈む**上下動（最大8 cm、毎秒3歩）と、歩ごとの左右の小さな揺れ（1.5 cm）。**傾き・視線の上下回転はなし**。目の高さより上へは動かないので、低い天井へ入り込まない |
| 強さ | 実際に進んだ速さ ÷ ダッシュの速さ。壁に当たって進んでいないときは0。開始・終了は毎秒4の速さでなめらかに変化 |
| 止まる条件 | 空中（ジャンプ・落下）、スライディング、ADS：毎秒10の速さですばやく消える（地上のダッシュの揺れが重ならない）。歩行・しゃがみ・伏せ・ADSの既存の揺れは変わらない（カメラの揺れはダッシュのみ） |
| 手元（銃・ナイフ） | ダッシュ中はカメラの歩みに少し遅れて沈む揺れ（銃：0.03単位・左右0.014、ナイフ：0.035・0.016、`sprintBob`）。そのぶん歩行の揺れを弱める。ADS中は無し |
| 変更していないもの | 移動速度・当たり判定・ゲームルール。体の位置・被弾判定・ネットワークで送る値（揺れはローカルのカメラ表示だけ）。弾は従来どおりカメラの位置から画面中央の方向へ出るので、照準と射撃はずれない（ホストの発射位置の許容範囲1.5 mに対して揺れは最大8 cm） |

## 確認

動画（等速、Editorの描画）：**上が「現在のコードでカメラの揺れを無効化した比較」、下が揺れあり**。厳密な「変更前」ではない（揺れを無効化すると、手元の計算も変更前と同じ経路になる）。

- `sprint_gun_off_top_on_bottom_realtime.mp4`：銃で歩行 → ダッシュ開始・継続 → 停止 → 壁へ向かってダッシュし壁で停止。
- `sprint_knife_off_top_on_bottom_realtime.mp4`：同じことをナイフで。
- `sprint_transitions_off_top_on_bottom_realtime.mp4`：ダッシュからジャンプ、スライディング、ADS。
- 単独の動画：`*_bob_off_current_code_realtime.mp4`・`*_bob_on_realtime.mp4`。

画像での計測（揺れなしとの差）：ダッシュ中、近くの床が最大で約24画素（1311×603の画面）上下し、銃は約19画素の幅で上下する（揺れなしは約3画素）。歩行・停止・壁で止まっている間は差0。

自動テスト（PlayMode `SprintBobTests` 4件）：歩行では揺れなし、ダッシュで強さ0.8以上・8 cm近くまで沈む、止まると0に戻る、壁で止まると0、ダッシュからジャンプ・スライディング・ADSで0.2秒以内に消える、ナイフでも揺れる。すべての瞬間でカメラは目より上に出ず、回転しない（照準＝視線の方向）。
